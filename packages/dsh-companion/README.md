# 主题盒子 · Mac arm64

## 当前本地评审候选

2026-11-06。本地回复风格候选 0.1.0-dev.35 内置「冷启动 / 0.4.0」与「档案暖白 · 鲸鱼娘 / 0.7.1」。启用插件并完成统一授权后，可在「主题盒子 → 皮肤库」选择。已有选择和各套偏好由原 profile 保留。

整套皮肤使用主题、桌宠和开场三个模块及8项公开参数。开场区域的「预览开场」与「启动时自动播放」复用已有动作/同一偏好；「启用本套开场内容」是单独的模块启停。停止后从「恢复本套皮肤」恢复，保留已调整参数和模块关闭选择。已选整套时，旧配置选择/控制由皮肤设置入口替代；未选整套的旧流程保留。

启用「启动时自动播放」后，按 ⌘Q 完全退出，再点原 DeepSeek Harness 图标。「冷启动」在 DSH 窗口内播完进入工作区，Esc 可跳过。「本套设置」也提供手动预览和声音开关。角色大小在当前桌宠窗口更新，空闲时保持高清待机画面，互动与动作按原片播放。选中「冷启动」后，菜单栏「07」提供「向左走」。旧素材 NOTICE 和 dsh-pet 上游 MIT 随桌面组件附带，本候选供 Mac 本地验证。

## 旧配置入口

当前包名为 `dsh-plugin-companion`，适配 Mac ARM64、DSH 0.2.1-rc.5 或 0.2.2-rc.1。插件内自带桌面组件，所有安装后的操作都从 DSH 侧栏「主题盒子」进入。

1. 在 DSH「添加插件」中输入发放者提供的 HTTPS `.tgz` 安装链接，安装源可选内置的中国大陆镜像。安装并启用后，在「主题盒子」→「开始使用」→「统一授权」输入激活码，点击「激活本机」。启动动画和桌宠共用一份设备授权。
2. 选择配置包；配置同时影响启动动画、动作素材和相处节奏。示例中提供日间与月色两套配置，支持导入、导出 JSON 配置文件。
3. 从原 DeepSeek Harness 图标进入。开场、启动桌宠及本套模块各自遵循对应偏好。
4. 在「桌宠控制」调整大小、行为和互动；在「授权与更新」刷新授权、解绑设备、检查更新并下载经过签名及摘要校验的私有安装包。

DSH 已在运行时，可用「预览开场」手动播放。从系统恢复窗口时会显示当前工作区。旧陪伴启动器可在「授权与更新」移除。

「授权与更新 → 插件 → 停用」使用 DSH 官方插件开关。恢复时在插件列表重新启用即可保留原授权和配置。

从旧名 `@local/dsh-companion` 升级时，先在 DSH 卸载旧版，再安装本包。更新或重装时，按 DSH 的插件管理流程安装下载文件，然后重新打开 DSH。授权和配置保存在独立目录。退出 DSH 时桌宠随之停止。

dev.8 起提供免登录的 HTTPS 在线安装入口，授权与适配更新继续使用独立 HTTPS 服务，并沿用 DSH 的官方代理路由。安装包仅包含公钥和服务地址，不包含签发私钥、管理员凭据或激活码。默认每份演示授权绑定一台设备，提供有限的离线续用期；具体有效期由发放者设置。从此前本机验证版升级时，需使用发放者提供的云端激活码。授权请求失败的本机诊断仅记录错误码和请求编号，不记录激活码、授权签名或硬件标识。

正式 Mac 签名公证、其他 DSH 版本、Windows 和长期稳定性仍需分别验收。当前使用本地开发签名，不改动官方 DSH 程序文件。示例素材按非商业自用范围使用，许可及署名保留在组件内的 ASSET-NOTICE.txt。

激活码的有效天数为 0 时，授权永久有效，插件显示“永久”。永久授权仍按约定的设备数和离线宽限运行，可以解绑、停用和恢复。永久授权需要本版或更新的插件；旧版有限期授权继续有效。

npm 发布准备已完成。正式发布前以发放者给出的 HTTPS 安装链接为准，尚未发布的包名不能用于 npm 在线安装。源码仓库与开源许可证后续另行公布。
