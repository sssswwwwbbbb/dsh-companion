## 第四条（单元-07）：变步长的单程拉伸

这一条的核心要求互相冲突——既要比 1.19 s 的版本从容，「指挥官」和「我已」都念稳，又不能丢掉年轻清亮偏薄的音色，也不能出现绵软和咔哒。最后采用的是**单程连续叠接、按帧切换分析步长**的做法：

- 整条只做一次连续的相位声码器合成，**不切段、不拼接**，声场从头到尾连贯，因此没有接缝处的"嗒"；
- 每一帧先判浊音／清音：**浊音帧**分析步长放慢到 1/1.62，**清音帧（z、s、t、g 这类字头）保持原速**，字头不做任何重合成，齿音维持原录音的脆度；
- 逐帧用峰值相位锁定维持谐波相干，避免金属感的抖动。

结果：

| 指标 | 值 |
|---|---|
| 基频 | 246 → **247 Hz**（p25–p75 为 237–255） |
| 与原始干声的谱包络相关度 | **0.999** |
| 高频段（4–9 kHz）与中高频（2.5–4 kHz）能量比 | **2.32**，原始 2.51，接近原录音的脆度 |
| 电平 | RMS **−20.4 dB**，与前三条（−21.8／−20.3／−19.4，均值 −20.4）对齐 |
| 波形连续性 | 全条无阶跃点（只有「指」「就」两处自然的爆破起音） |
| 节奏 | 「指挥官」0.78 s → 约 0.30 s 呼吸位 → 「我已就位」0.97 s，整句 1.90 s |

关于"声音偏小"：之前几版是按峰值 −3 dBFS 归一，而这一条停顿多、峰值与平均能量差得远，听着就比前三条轻；这一版改成**按 RMS 与前三条对齐**，峰值留在 −4.8 dBFS，听感和音量一致。

## 音色来源与可用范围

- 声线由合成语音生成，**不是**对某位真人声优的音色复刻，不含真人声音素材。
- 可用于本项目内二创、自用、非商业用途；不得对外宣称是原作声优的表演，不得单独转售或分发声音素材。
- 若要更强的机器感，只改 `_wet` 的环调深度与梳状反馈，`_dry` 不必重生成。
