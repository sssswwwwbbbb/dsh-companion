# 黑焰 · 使用说明

DSH 第二套皮肤，无桌宠版。主题名「黑焰」，角色阿斯特（封存编号 07），用户称呼「契约者」。
作者 Dr.S。仅作者本人分发的版本，获取者自用。

---

## 一、适用环境

| 项 | 要求 |
| --- | --- |
| DSH | `0.2.2-rc.1` |
| 主题盒子 | `1.0.0` 或更高；本文按 `1.1.0-dev.2` 描述 |
| 平台 | macOS ARM64 已实测；Windows x64 未实测 |
| 包 | `black-flame-0.2.1.zip` |

低于 `1.0.0` 的主题盒子不认提示配色与场景预设，请先升级。

## 二、安装与应用

**从云端皮肤库装**

1. 打开 DSH → 左侧「主题盒子」→「皮肤库」。
2. 找到「黑焰」，按客户端提示下载。
3. 下载完成后点「应用皮肤」。

**从本地 ZIP 装**

1. 同上进入「皮肤库」，点右上角「导入本地 ZIP」。
2. 选 `black-flame-0.2.1.zip`。
3. 卡片出现后点「应用皮肤」。

应用后立刻生效：配色、图标、入口徽记、底栏与卡片封面都会换成本套。

## 三、你会看到什么

- **工作区**：烬色米白（浅色）/ 封存舱暗紫（深色）两套配色，50 个位置的图标换成中性色线条图标。
- **开场**：9.35 秒，有声。容器门打开 → 阿斯特走出 → 回到工作区。
- **入口徽记**：侧栏「主题盒子」图标变成角族徽记。
- **皮肤库卡片**：显示本套封面。
- **底栏**：绑定模型后显示对应场景徽记（见第六节）。

## 四、本套设置

「主题盒子」→「本套设置」，页内有四个分组：**常用 / 角色 / 更多 / 场景**。所有改动按皮肤保存，换到别的皮肤再换回来仍然保留。

### 常用

| 项目 | 默认 | 说明 |
| --- | --- | --- |
| 背景浓度 | 0.04 | 聊天背景图的透明度，0–0.15。调高更明显，调高到 0.12 附近是作者推荐的用法 |
| 入口标识 | 开 | 关掉后侧栏恢复插件默认图标 |
| 工作区细节 | 开 | 本套版式的细节层 |
| 界面动效 | 开 | 界面过渡动画 |
| 工作反馈 | 开 | 执行状态的低亮度反馈 |

### 角色

- **回复风格**：称呼「契约者」、冷淡短句的语气。默认开启，也可以在会话标题旁直接开关。想用自己习惯的语气就关掉。
- **主题角色**：把阿斯特的身份设定加入该会话。默认不启用，需要逐个会话在标题旁点「主题角色」开启。工作和工具规则始终优先于角色设定。

### 更多

开场相关：

| 项目 | 默认 | 说明 |
| --- | --- | --- |
| 开场声音 | 开 | 关掉后仍有画面，只是静音 |
| 减少开场动态 | 关 | 打开后开场退回静帧，不做动画 |
| 预览开场 | — | 立刻播一遍，播完回到当前会话，不改自动播放设置 |

### 场景

见第六节。

## 五、三类工作区提示

在工作区切来切去时会短暂出现一句话，不打断输入，也不占位置。三条都可以单独开关、调时长、位置与入场效果，还能预览。

| 场景 | 文案 | 默认 | 出现时机 |
| --- | --- | --- | --- |
| 回到 DSH 时招呼 | 你回来了。火还在。 | 开 | 离开 DSH ≥15 秒后回来，间隔 ≥60 秒 |
| 切换会话时提示 | 换了一页。 | 关 | 同一工作区内切会话，间隔 ≥4 秒 |
| 切换工作区时提示 | 我跟着过来了。 | 关 | 切到另一工作区的会话，间隔 ≥4 秒 |

- 时长设为 6 / 2.5 / 3 秒，位置分别是输入框上方、输入框右上、窗口右上。
- 三条共用一套底色与字色，只用描边区分：回来是火的红，切会话是中性色，切工作区是余烬金。
- 只展开目录不触发；刚打开会话保持安静。
- 开启「专注与休息」时会暂停提示。

觉得吵就把三条都关掉，不会影响其它功能。

## 六、场景预设

「本套设置 → 场景」可以把本套的外观绑到具体的模型或工作区上。选择后自动保存。

**随模型变化**（在工作区底栏显示徽记）

| 预设 | 徽记 | 切换提示 |
| --- | --- | --- |
| 炽焰 | 红盘白角 | 炽焰档。烧得快。 |
| 余烬 | 金盘白角 | 余烬档。省着火。 |
| 封存 | 灰盘白角 | 封存档。没动火。 |

做法：「选择模型」选一个已配置的模型 →「工作区形象」选一个预设。想取消就选「使用皮肤默认」。

**随工作区变化**（改该工作区的强调色与底栏标识）

| 预设 | 强调色（浅 / 深） | 切换提示 |
| --- | --- | --- |
| 封存舱 | `#C0282E` / `#FF6A3C` | 封存舱。冷。 |
| 余烬层 | `#8A5A16` / `#E7A45C` | 余烬层。脚下是热的。 |
| 警戒层 | `#B2541E` / `#F2A93B` | 警戒层。别出声。 |

映射按皮肤保存；换肤再换回仍在。

## 七、开场

- 从原 DSH 图标启动时自动播放，9.35 秒，有声。
- 播放中右上角有「进入工作区 · Esc」，随时可以跳过。
- 播完自然进入工作区，不会改变你已经打好的草稿。
- 想看一次：本套设置里点「预览开场」。
- 声音开关与「减少开场动态」见第四节。

## 八、停用与回退

- **只关本套**：「本套设置」右上「停止本套效果」。工作区回到默认外观，设置保留，随时可恢复。
- **换回别的皮肤**：皮肤库点别的卡片「应用皮肤」。两套设置互不影响。
- **卸载**：皮肤库卡片上的「卸载」。已领取的下载名额不会退回，重装同一版本免费。

## 九、常见问题

**图标只变了一部分？**
当前主题盒子的图标替换只覆盖输入区与文件类型图标（文件夹、代码、表格、图片、文本）。侧栏导航仍是宿主原图标，这是引擎侧限制，不是本套缺素材。

**提示不出现？**
三个条件：对应开关打开、不在「专注与休息」、且满足触发间隔（回到 DSH 需离开 15 秒以上）。也可以直接点「预览提示」看效果。

**深浅色怎么切？**
跟随 DSH 的主题切换，两套都做了完整配色。

**开场没有声音？**
检查「开场声音」是否打开；系统音量、静音键也会影响。

**能改颜色吗？**
不能。色板随包固定。想换配色需要另做一套皮肤。
