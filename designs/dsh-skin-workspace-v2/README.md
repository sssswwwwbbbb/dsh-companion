# 档案暖白 · 工作区细节 V2

2026-11-04。沿用已定 R3 暖白、铜橙、银蓝与鲸鱼娘，深化完整工作界面、成套语义图标和合理演出。入口 [index.html](index.html)，[本地预览](http://127.0.0.1:4314/dsh-skin-workspace-v2/)。本目录是可点的独立设计稿，使用本地虚构会话与定时示例回复；不读真实会话、不调用模型，不代表生产接入完成。

## 沉浸一致性

统一世界是“暖白档案室＋银蓝鲸鱼娘”。导航的索引页、消息的便笺、引用的资料签、等待的轻扫描和完成的归档回执，采用同一套纸面材质、折角母形、线宽与节奏。铜橙承担操作，银蓝承担角色与资料线索；衬线只用于短标题，正文稳定清楚。角色沿原银蓝发色、白褶边与蝴蝶结，工作与陪伴短句保持同一份平静语气。常见功能词和状态保留本义，主题表达融入造型与反馈。

主控整稿审核还要检查：常用界面各处的细节能否被辨认为同一主题，图标与动效是否共用同一语言，角色演出是否属于同一个世界，开关关闭后功能语义是否仍完整。用户举例用于启发全流程规划，不把新建/删除机械作为演出边界。

## 主题演出 R2

用户明确反馈上一版「动效不明显、普通、缺少眼前一亮的感觉」。旧克制稿与静态审图结论保存在 [review/r1-quiet](review/r1-quiet/scope.md)，不作为这一版体验通过。

新的焦点是完整「开卷」：暖白封面有装订脊与铜橙索引，封面翻开后，纸页、原有鲸鱼娘和银蓝扫描连成一个场景；开卷印记落下，再将整页收回导航陪伴位。正常工作界面保留在周围，输入不等待演出。顶部 **主题演出** 直接重播，**跳过演出 / Esc** 立即退出；点击输入、滚动阅读、改变布局或离开工作区也会打断。

[开卷实录 MP4](review/theme-opening-demo.mp4) · [开卷 GIF](review/theme-opening-demo.gif) · [完成反馈实录](review/reply-completion-demo.mp4) · [开卷逐段画面](review/opening-sequence.jpg)。这些是浏览器实拍屏幕序列，不是补帧制作的概念视频；录像采集帧率低于实际浏览器渲染，连续流畅度以本地预览实际播放为准。

| 场景 | 表达与触发 |
| --- | --- |
| 应用主题 / 主动重播 | 约3.9秒开卷，约300px方形视频区域呈现既有全身角色。此独立稿打开时示范一次；真实接入拟绑定主题应用/手动重播，不追加一次日常冷启动开场 |
| 新的一页 | 约520ms纸页展开，输入立即可用；不重播完整开卷 |
| 寻找、切换与置顶会话 | 搜索立即筛选；切换保留阅读位置；置顶以索引位置过渡解释关系 |
| 输入与发送 | 焦点铜橙细线，附件展开、便笺入页；草稿不因外观或演出变化消失 |
| 打开引用 | 编号资料签约620ms从引用飞入原文摘录，资料侧栏就近展开；维护正文阅读锚点 |
| 工作过程与等待 | 进入执行时有限两轮墨迹扫过，之后静态文字；不用动画计时或假百分比代表工作进度 |
| 需处理 | 保持原问题、文字及处理入口；预演主题、关闭装饰/侧栏均不解除请求 |
| 本轮新回复完成 | 约2.4秒归档便笺、既有角色一次回应与回执落印。只响应当前会话的新完成；回看旧内容时不强制拉到新结果，历史会话不补播 |
| 中断、取消与停止 | 独立静态语义，保留草稿；不出现成功便笺或成功角色反馈 |
| 删除等管理操作 | 成功后短收起可作为候选；确认、撤销和恢复从属宿主真实功能，本稿不建立删除协议 |
| 配色与布局调整 | 保留内容、输入和阅读关系；清理当前演出，避免动画停在错误的位置 |
| 离开工作区、隐藏与减少动态 | 清理场景并暂停媒体；显式重播可看静态开卷页，状态与操作不丢失 |

界面动效、角色呼应分别可关；系统减少动态与显式开关都有效。角色呼应关闭时开卷保留静态既有角色；界面动效关闭/减少动态时主动预览显示静态页，不自动占用阅读。WAAPI负责纸页、裁切、线条及共享位置，不新增依赖。角色复用A2原始idle/react（各约0.63MB），react只播一次，不制作新帧、不追加声音。

### Direction contract（开发记录）

- **THESIS**：像翻开自己的档案，主题的角色、资料和工作界面通过同一张纸联系起来。
- **OWN-WORLD**：沿用R3暖白、铜橙、银蓝、短衬线标题、折角与1.55px图标笔触；既定银蓝发鲸鱼娘保持身份一致。
- **STORY**：认出封面，见到陪伴者，看到纸页被扫描和盖印，最后回到可以继续工作的界面。
- **FIRST VIEWPORT**：本地稿首次打开即示范一次完整开卷；导航、资料和输入仍在周围，重播与跳过都直接可见。
- **SIGNATURE**：有装订轴的翻页、编号资料签的来源转移，以及角色随开卷页回到导航的收束。
- **BUDGET**：开卷约3.9秒，完成反馈约2.4秒，普通操作160–620ms；演出可中断，视频复用，减少动态保留静态反馈。常用工作区是Operate，主动主题演出是局部Experience。

## 试用顺序

打开后先观看完整开卷；点击「主题演出」重播，Esc或输入框可立即打断。顶部「情景反馈」在完成状态滚到回执并重看归档便笺，在需处理/中断/停止状态保留各自语义。新建会话、快捷起稿、连续发送、引用/原文、置顶、专注阅读和资料侧栏都可操作。外观选项可分别关闭界面动效、角色呼应或减少动态，问题与输入继续保留。

## 资源与参考

图标原稿、可复用sprite和PNG清单分别在 [icons.json](icons.json)、[assets/icons.svg](assets/icons.svg)、[icons-manifest.json](icons-manifest.json)。SVG为本轮在项目内绘制的几何符号，不混用多套库；PNG由本地Canvas 2D的sRGB画布等比栅格导出，来源摘要逐项保留。它们是设计资源，不是可直接安装的完整DSH皮肤包。

动效原则另参考 [Apple Motion](https://developer.apple.com/design/human-interface-guidelines/motion) 与 [W3C Animation from Interactions](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions)：用动态解释反馈与连续性，并保留减少动态的路径；当前时长与演出是本套的设计判断。

参考 [Linear的导航与图标减重](https://linear.app/now/behind-the-latest-design-refresh)、[Craft的文字/页面分层](https://support.craft.do/hc/en-us/articles/10293992410780-Document-Styling)、[Zed按文件/目录组织图标主题](https://zed.dev/docs/extensions/icon-themes)、[dsh-pixel-ui的DSH整套表达](https://github.com/zhang66633/dsh-pixel-ui)。采用组织思路，没有复制这些产品的图片、字形或代码，不引入它们的分发许可。新增图标沿本项目许可决策处理，不另行宣告开源许可证。

[tokens.css](tokens.css)原样复用R3；角色图集和A2视频通过相对路径引用原项目素材，来源与使用边界沿 [R2角色NOTICE](../dsh-skin-v1/assets/whale-unified-r2/NOTICE.md)及[A2 NOTICE](../dsh-skin-v1/assets/whale-motion-a2/NOTICE.md)，不扩张公开分发或商用授权。原SVG入口、旧关键稿、准确0.7.1、原媒体和生产代码均不由本节点修改。

图标资源已形成56枚SVG原稿、一个sprite、112份浅/深透明PNG（96×96，sRGB，合计174,636字节），在完整界面与图标页展示；图标页可查找并查看16 / 20 / 24px实际大小。中性PNG使用本套明暗前景与银蓝辅助色，SVG原稿可继承文字色；选中、禁用等映射由真实适配层承载。[图标资源ZIP](archive-warm-icons-v2.zip)仅含图标和清单，不是可安装皮肤。

本地检查：[未改图标资源的原校验](review/resources.json)、[正常界面原操作记录](review/browser-checks.json)、[本轮演出与打断检查](review/browser-checks-r2.json)、[最终源码摘要](review/source-freeze.json)。主对话正文14px、资料正文12px、次要标签最低11px；1440×900、1280×720和1100×760检查无整页或阅读区横向溢出。完成、停止、需处理、草稿/附件、阅读恢复与系统减少动态分别记录，未测真实DSH接入或长期帧率。

机械检查曾提示暖白配色、11px次要字及页签边界。暖白沿既定世界保留；资料正文升至12px、页签文字显式留出上下间距，11px用于紧凑元信息。整稿另交独立审图与主控实际点击，不作全套自动通过的声明。
