| 检查 | 结果 |
| --- | --- |
| 61 个颜色变量 | 全部存在于 rc.5 |
| 49 个图标替换键（`send` 已改用原生） | 全部至少一条选择器可命中 |
| 离线校验 | `skin-author-check` 对 rc.5 与 rc.1 均 `valid`，模块 `enabled` |

限制：rc.5 开发构建为 ad-hoc 签名，无法在与已安装 rc.1 同机的情况下启动第二个实例（Bundle ID 冲突、重签名后崩溃），因此 rc.5 的 GUI 实机复验待补。rc.4 官方未发布 macOS 包，不在支持范围。
