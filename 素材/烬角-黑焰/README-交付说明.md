`_dry` 是干声，`_wet` 是临场版：只做 7 kHz 以内低通 + 一层很轻的空腔混响（wet 0.26），模拟站在金属腔体里说话的空气感；不再有机械环调、梳状和饱和，因为角色是角族少女，不是机械造物。两条等长，可直接对画面二选一。源素材为单声道合成，交付按清单要求导出立体声（L=R）。

**电平口径（v3.3 修）**：台词干声 RMS −20 dB、峰值天花板 −3 dB；音效 −16～−24 dB、峰值 ≤ −3 dB；环境底噪 −32 dB（峰值 −19 dB）；开场混音整体 RMS −20 dB、峰值 −1.7 dB（不做硬削顶）。上一版交付的音轨在转立体声时被读成满量程噪声（全程 RMS −7.7 dB、峰值贴 ±1.0），已整条重做，成片音轨同步换新。

## 六、接入说明

1. 图标按 file-id 覆盖到皮肤目录的 `light` / `dark` 两套；落在强调色填充按钮上的位置改用 `light-neutral` / `dark-neutral` 一套（`send` / `stop` 已按近白准备）。
2. 状态图标语义：start（播放）/ running（时钟）/ need-action（感叹）/ done（对勾）/ stop（方块）/ failed（叉）；配色语义见色板文档。
3. 工作区关键稿是版式参考，不是切图；实际接入以 CSS 变量取色即可。
4. 开场静帧可直接作为开场视频首帧；音频按 `opening-mix-10.5.wav` 对位。
5. 角色立绘如需分层，三视图已给出正/侧/背三面，可按面拆图。

## 七、已知限制

- 角色立绘是 AI 以手绘参考为锚点生成的三视图，不是逐层可编辑的分层工程文件；需要分层请以三视图为基准重新描线。
- 台词为合成音色，非真人声优；三条台词分别生成后做了电平与音色对齐，句内过长停顿已压到 0.12 s 气口，逐句绝对音高会有 ±10 Hz 波动。
- 正片人物口型未与台词逐字同步，现为时间轴与情绪节奏对齐。
- 图标为线性几何矢量，与手绘插画风格不同；需要插画风徽记可另外出图。

## 八、运行素材规模

`exports/` 全量为交付与开发参考，`exports/backgrounds/workspace-*-1440x900.png` 仍是界面版式参考图（不在成片里出现）。实际接入按主题明暗取其一，运行集约 90–100 项（图标 56 + 入口徽记 1 + 小操作 3 + 状态 6 + 头像 1 + 背景 2 + 静帧 1 + 待机循环 1 + 正片 1 + 音效 4），在 128 项以内；单图最大 1.9 MiB（三视图之外的封面/背景均 < 1 MiB），单视频 8.2 MiB（< 16 MiB 上限），若同时带入中性色一套会超 128 项，需按页面位置换入而不是整包替换。
