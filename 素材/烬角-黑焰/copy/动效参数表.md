# 动效参数表

规格：24 fps。静态替代一律为同尺寸 PNG；静音表现指关闭音效后的显示与时长不变（仅此一条音轨静默）。

## 一 工作区待机循环

| 项 | 值 |
|---|---|
| 触发点 | 工作区空闲 8 秒后自动进入；用户有任何输入或状态切换立即退出 |
| 起止帧 | 第 0 帧 → 第 47 帧（48 帧，2.00 秒，首尾同相位可无缝循环） |
| 循环点 | 第 0 帧 / 第 48 帧等价，循环回跳无跳变（采用正弦呼吸曲线，首尾亮度与缩放一致） |
| 动效内容 | 徽记呼吸：亮度 0.90→1.10 正弦往复，整体缩放 ±2%，中心不动 |
| 静态替代 | `exports/brand/idle-loop-still-512x512.png`（静止徽记，暗底 #0F0A12） |
| 静音表现 | 无音轨，静音与有声表现完全一致 |
| 终态（恢复到稳定画面） | 退出时定格在亮度 1.0 的静帧，0.3 秒淡出回到 `idle-loop-still` |
| 文件 | `exports/brand/idle-loop-512x512.mp4` |

## 二 小操作三态

三个场景：新会话、发送、复制成功。每个场景 × 明暗两套，各三帧。帧内为 96×96 图标位。

| 场景 | 触发点 | 初态 → 短反馈 → 终态 | 时长 | 静态替代 | 音效 |
|---|---|---|---|---|---|
| 发送 | 用户按下发送键 | `initial`（静止）→ `feedback`（放大 1.08、提亮 1.15、外发光 3px，第 0–6 帧）→ `settled`（回落原尺寸，成功色底 35% 叠印，第 7–12 帧保持） | 0.5 s | 三态 PNG 各自即成静态替代 | `exports/audio/sfx-ui-tick.wav` |
| 新会话 | 点击「新建会话」 | `initial` → `feedback`（同上，第 0–6 帧）→ `settled`（第 7–12 帧） | 0.5 s | 同上 | `sfx-ui-tick.wav` |
| 复制成功 | 复制完成事件 | `initial` → `feedback` → `settled`（成功色底表示完成） | 0.5 s | 同上 | `sfx-ui-tick.wav` |

文件命名：`exports/actions/states/action-<场景>-<light|dark>-<initial|feedback|settled>-96x96.png`，共 18 张。终态色底：浅色 #3A7D44 / 深色 #46A960，叠印强度 35%。

## 三 任务执行状态

| 状态 | 图标（明暗各一） | 触发点 | 低亮度循环 | 静态替代 | 音效 |
|---|---|---|---|---|---|
| 开始 start | `state-start-96x96-{light,dark}.png` | 任务入队 | 无 | 即图标本身 | 无 |
| 执行中 running | `state-running-…` | 开始执行 | 有：图标亮度 1.0↔0.82，1.4 s 一循环，首尾同相位 | 取亮度 1.0 帧 | 无（可用环境声 8 s 底噪循环） |
| 需处理 need-action | `state-need-action-…` | 需要用户输入 | 有：图标 + 感叹号 0.4 s 一次轻微脉动 | 取脉动峰值帧 | `sfx-ui-tick.wav` |
| 完成 done | `state-done-…` | 任务结束成功 | 无 | 即图标 | `sfx-ui-tick.wav` |
| 停止 stop | `state-stop-…` | 用户中断 | 无 | 即图标 | `sfx-lock-release.wav` |
| 失败 failed | `state-failed-…` | 执行失败 | 无（一次 0.2 s 抖动后静止） | 抖动前帧 | `sfx-end-hit.wav` |

## 四 主题小演出（点击皮肤管理入口）

| 段 | 时间码 | 画面 | 声音 |
|---|---|---|---|
| 1 | 0.00–0.30 s | 入口徽记轻微下压 0.96，火星从描边内侧冒出 | `sfx-ui-tick.wav` 入点 0.00 |
| 2 | 0.30–1.10 s | 火星沿描边绕一圈，徽记由线稿变为实心赭红 | `sfx-flame-ignite.wav` 入点 0.30 |
| 3 | 1.10–1.90 s | 徽记后侧掠过一道角影（阿斯特的侧脸剪影），毛发被热流托起 | `sfx-scan.wav` 入点 1.10 |
| 4 | 1.90–2.60 s | 角影收回，徽记回到静止，火焰余辉淡出 | `sfx-end-hit.wav` 入点 2.30 |

- 关键帧：`exports/brand/entry-mark-dark-96x96.png`（段 1 起始）、段 2/3 的中间态可直接以入口徽记 + `exports/character/bust-1024x1024.png` 的侧脸裁片叠合示意。
- 前后场景：工作区深色稿（`exports/backgrounds/workspace-dark-1440x900.png`）。
- 混音：`exports/audio/sfx-flame-ignite.wav` + `sfx-scan.wav` + `sfx-ui-tick.wav` + `sfx-end-hit.wav` 按上表入点叠成 2.6 s；可直接用现有四条单音在引擎侧合成。
- 跳过后的落点：立刻停在段 4 的静止徽记，与 `idle-loop-still-512x512.png` 对齐，不播放余下音效。
- 静音表现：时长与帧序不变，仅四条音效静默。
