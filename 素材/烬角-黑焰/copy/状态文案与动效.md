# 6 态状态图标：短文案与动效说明

| 状态 | 文件 | 界面短文案 | 动效 |
|---|---|---|---|
| start | `state-start-96x96-{light,dark}.png` | 「开」 | 图标从 0.86 缩放到 1.0，120 ms，ease-out；底部一条 2px accent 光线从左扫到右 |
| running | `state-running-96x96-...` | 「在烧」 | 时钟指针以 2 s 一圈匀速旋转；外圈 accent 描边以 1.2 s 呼吸（透明度 40%↔100%） |
| need-action | `state-need-action-...` | 「等你一句」 | 感叹号每 1.6 s 轻点头一次（±8° 摆动，220 ms）；金色描边常亮 |
| done | `state-done-...` | 「好了」 | 对勾先落下 1.05 倍再回弹到 1.0（180 ms），随后整体淡出到 60% 驻留 |
| stop | `state-stop-...` | 「停了」 | 方块向内收 4% 后停住，不循环；配一次 12 ms 的百叶结式抖动 |
| failed | `state-failed-...` | 「断了」 | 叉号 1 次 320 ms 的左右横抖（±2px），色值压暗 15% 后驻留 |

通用规则：动效只在状态切换时播放一次，running 是唯一循环态；所有动效不动画整体位移超过 4px，避免在 16px 尺寸下抖动。图标基色为 accent，语义色只在 need-action / done / failed 上替换。
