# 工作区场景提示反馈处理 · 1.0

反馈来源：second-skin-workspace-cue-request-2026-11-08.md。三项主要问题均纳入封版：

| 反馈 | 1.0 处理 |
| --- | --- |
| 无托盘不显眼 | 提示卡统一有底色、1 px 描边、内边距和圆角，默认复用宿主 toast 色 |
| 时长固定 | 每条 `seconds` 为 1–8 秒，普通旧包默认 4 秒，用户逐条覆写 |
| 贴底边 | `above-input` 输入框上方居中、`bottom-right` 输入框右上方、`top-right` 窗口右上角、`bottom-bar` 保留底栏选项 |
| 样式配色 | 可选 `colors.background/text/border`，每项 light/dark 十六进制颜色 |
| 不知道效果 | 每条可预览；会返回会话，按当前设置显示，不改变开关 |
| 各场景缺少差异 | 每条独立位置、时长与 `effect: none/fade/slide`。冷启动分别用居中、输入框右上、窗口右上默认 |

旧的 text/default 声明继续可用，无须为获得新默认容器而重做素材。旧布尔覆写继续保留。新字段请使用 1.0 同版校验器，完整字段与素材清单见 [最新交接](skin-kit-v1/README.md)。

角色欢迎动画/小演出、新会话空白页开场和工作区完整媒体转场列入后续内容接口，不能在 workspaceCues 中自行填写 media/audio。现阶段可先交分镜、静态回退和短片小样，待媒体接口确认后接入。

“生成中点击会话行未切换”仍是未定性观察，不与此次提示渲染问题混作已修复事项。按复现和宿主行为另行核对。
