# 皮肤库与独立下载队列验收记录

日期：2026-11-08。客户端候选 `1.1.0-dev.4`，构建号 `10004`。最近一次 Windows 用户验收为 `1.1.0-dev.3`；本轮 Windows 包已生成，等待一次集中验收。本轮没有提交 Git、发布 GitHub Release 或上传/替换任何皮肤包。

## 本轮行为

- 下载脱离设置/应用操作的全局忙状态。默认同时下载 2 套，其余按点击顺序排队；下载时可以继续搜索、翻页、切换列表或添加其他任务。
- 每项任务独立显示进度、取消、完成或失败；失败和取消可重试。超过 8 项可展开全部任务。下载完成只安装，用户点击“应用皮肤”才切换外观。
- 队列属于插件运行实例，切换页面继续运行；退出 DSH 或停用插件取消尚未完成的任务，不提供跨退出自动续传。
- 切换激活码/解绑先取消并等待旧任务，任务始终绑定原授权。新授权不会被旧排队任务消耗名额。
- 首次开始授权下载就会领取皮肤；取消可能发生在服务端已领取之后，不返还名额。同 ID 更新、重装均不重复计数，卸载也不返还。`skinLimit=0` 始终不限量。
- 在线和已安装分成两个列表。支持名称/ID搜索、含桌宠/不含桌宠筛选；在线列表额外支持最近更新/名称排序、只看已领取。当前皮肤在已安装列表中优先显示。
- 在线接口按 ID 选最新版本后筛选和分页，默认每页 24 套，最大 48；客户端每页展示 24 张卡片，封面进入可见范围才请求。已安装列表本地搜索/筛选/分页，每页最多 24 张卡片。
- 列表支持前后翻页及数字跳页；翻页回到该列表搜索栏。安装多个版本时分别展示和卸载，默认保留共用设置。

## 接口变化

`POST /v1/skins/catalog` 继续使用现有激活凭据和签名响应，新增参数 `page`、`pageSize`、`q`（最长80字符）、`module`（all/pet/no-pet/theme/startup）、`sort`（newest/name）、`owned`（布尔）。响应保留 `skins`、`quota`，新增 `page`、`pageSize`、`total`、`pages`、`query`。越界页落到最后一页。`releaseId` 可查询单个准确版本，详情查询不消耗下载名额。

客户端新增 `skinDownloadAdd` 与 `skinDownloadCancel`，返回任务快照；旧 `skinDownload` 阻塞调用保留兼容。目录请求独立于普通设置操作，迟到的状态/目录/队列响应不会覆盖较新的分页和任务；同授权下已领取数量不会被迟到的旧状态回退。

皮肤包格式与配置合同没有新增必填项，制作者无需为本轮库升级修改皮肤。线上发布继续使用已有制作流程 A/B 和管理命令，皮肤包由维护者自行上传。

## Windows 一次集中验收

1. DSH `0.2.2-rc.1` 覆盖安装 Windows x64 `1.1.0-dev.4`，确认原授权、选择和设置仍在。
2. 连续下载两至三套未安装的皮肤（若已全部安装，可先卸载并保留设置），确认能继续点其他下载、搜索和切换“已安装”；任务可取消/重试，下载完成不会自动换肤。
3. 检查在线搜索、模块筛选、排序和“只看已领取”，再从已安装列表应用/卸载一套。正式线上仅 3 套，不用人为制造几十页；上千套分页已在隔离数据中验证。
