## 从同一处开始

1. 打开侧栏**陪伴 → 常用设置**，默认即为此页。当前横幅显示“档案暖白 · 鲸鱼娘”；需要时可点“重新应用本套”。普通入口已移除A/B回归选择，历史选择仍保留恢复。主题到普通会话工作区查看，管理页使用本轮移植的R3独立版式。
2. 在常用设置调整**背景浓度、角色大小、智能互动**，并分别启停工作区主题、鲸鱼娘桌宠和本套开场内容。关闭模块会收起子项并保留参数，重新开启沿用原值；不支持的字段不显示，不可用时说明原因。
3. 在常用设置的“开场与进入”区，区分“本套开场内容”和“启动时自动播放”；后者继续使用原全局偏好。关闭自动播放后仍可点“预览开场”，手动预览不修改自动偏好。成片为**8.20秒静音**，一张16:9主画面内右上显示“进入DSH”、底部显示细进度；Host就绪后才可进入，未提供ESC。应用、恢复或运行中启用不强制重播，桌宠可独立关闭。
4. 打开**陪伴 → 更多设置**，调整本套人设、互动模型、本次运行的历史轮数、允许说话和允许动作；“和桌宠说话”的**桌宠专属输入**及“轻点一下”也在此页。点击角色或专属输入可触发短话、回应动作或安静陪伴。模型跟随DSH已配置默认模型；没有可用模型时使用本套本地回应。当前本轮实机验证未调用真实外部模型，质量仍待体验。
5. 左侧点**停止效果**，需要时再点**恢复效果**；模块关闭选择和参数保留，恢复不补播过期回应或开场。底部**重置本套**清除本套参数覆写，保留停止及模块启停意图。首次未选皮肤时，停止后不出现无效的恢复本套入口。
