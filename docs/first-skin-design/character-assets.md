## R2 当前角色方案

用户要求桌宠与主题形象一致并优化。当前预览已统一使用 assets/whale-unified-r2/character-atlas-r2.png：由内置 imagegen 根据扫描关键帧生成，1254×1254 RGBA、2×2 等分、每格 627×627，分别为 idle / react / greet / stretch。原始输出未编辑，CSS 只显示对应方格。

固定识别点为银蓝长发、蓝青色眼睛、白色褶边头饰和深蓝侧蝴蝶结；四个姿态保持相同脸部、比例和服饰，采用柔和立体 Q 版材质。设置横幅、桌宠衔接和角色页使用同一资源，不再呈现旧视频人物。

扫描片只展示面部及局部领口。完整女仆裙、领结、鞋履为本轮设计延伸，不声称已找到原片全身设定。没有添加未经参考支持的鲸尾。当前为可审查稿，未获得视觉定稿确认。

姿态切换辅以 CSS 呼吸、侧倾与位移，react=1.8s、greet=2.6s、stretch=3s；不是逐帧动作素材。减少动态保留静态 idle；停止后隐藏桌宠并清空待播反馈。实际运行合同尚未消费 R2 图集，不能把 R1 宿主通过证据用于 R2 角色。

图集的透明边界及分格检查见 reports/first-skin/r2-atlas-audit.json；生成提示、精确摘要和来源说明见 assets/whale-unified-r2/prompt.md、generation.json、NOTICE.md。

## R1 的 12 动作实测

所有 WebM 画布 640×360、24fps，声明 alpha_mode=1，解码后确有透明像素。上游配置每段 10.042 秒，ffmpeg 容器摘要四舍五入为 10.04 秒。每段只采首帧、5 秒、结束前约 90ms，不能替代逐帧美术验收。

alpha 边界阈值 >16/255；脚底 Y 取三帧最大值，X 暂定 0.5。这是几何参考，不是官方动作锚点合同。所有采样画布边缘 alpha 最大值为 0；没有据此宣称整段都无裁边。

idle 首末均差 23.93，look/wake 更高，不能宣称全部无缝循环。R1 沿用既有 idle/sleep 循环方式；正式连续播放和跨动作接缝仍需修订。greet/react/stretch 为单次动作，结束或高优先级中断后回待机。

R1 预览按画布高度呈现 16:9 透明视频，避免按方框宽度缩小角色。待机首帧有效高度 267/360；设计画布 160px 对应有效角色约 119px。运行包 size=100 是百分比，需原生几何校准，不能互填。

## 缺失与未入选

- 专属提起、落地、短点击、专注、错误、完成短动作没有可验证资源。可保留既有拖拽行为，不声称新增动画。
- 没有模型对应角色或服装，不显示模型映射设置。
- 没有选择音频；扫描原片实际含音轨，原型始终 muted。
- look/sleep/wake 仅为对照和后续选择，不增加默认自主玩法。
