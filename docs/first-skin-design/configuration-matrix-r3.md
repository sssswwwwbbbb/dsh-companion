## 规则编辑与失效约定

- 本轮模型是 example-deepseek / example-other 等示例 ID，不读取真实 DSH 模型。按精确模型 → 任意模型 → 本套默认选择第一条启用规则；同一模型/事件的启用规则禁止重复，最多八条。
- 只允许 completed 和 needs-user 两个事件样例。需要处理强制 idle 静态，不接受庆祝动作；不能把规则文本当脚本或模板执行。
- 禁用映射保留规则，无匹配回本套默认；规则不跨皮肤、后台会话或未验证事件执行。切换示例模型/会话解除旧的模拟反馈，停止清空待播队列；用户未处理的会话状态不由气泡开关消除。
- 实际底座须提供事件代次、当前会话 ID、真实模型 ID、需处理解除/会话切换失效，再扩展 feedback/mapping 模块及版本。现有协调、存储、资源与撤销机制复用。

## 动作范围先收敛

先保留 idle/react/greet/stretch 四姿态；首轮完整动画只验证 idle 与 react。需要处理用静态 idle，不另造庆祝/错误表演；walk/run/eat/play/sleep 等不因为合同有槽位就自动列为本套首版玩法。完整动作制作在配置与角色候选复审后推进；当前不批量制作、不以静帧视频冒充完整动画。
