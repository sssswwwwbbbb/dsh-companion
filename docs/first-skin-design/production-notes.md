# 首套实际制作步骤与复用输入

2026-11-04。当前已到dev.14本机体验修正版，见[主控实机回执](../first-skin-installed-repair-2026-11-04.md)。以下沉淀实际工具与输入，不是制作器/上传/市场实现，也未给项目选择许可证。

1. **先定实际覆盖。** 当前三模块：官方工作区主题、两状态桌宠、独立开场。只公开实际合同支持的八个参数；原型候选不直接灌入运行包。模块字段与生命周期、授权、存储、撤销复用现有dsh-skin-core/官方SDK。
2. **固定同一角色。** 以扫描近景的银蓝发、青蓝瞳、白褶头饰与深蓝蝴蝶结为基准；imagegen先少量图集/连续帧再判断质量。A1仅idle/react各12帧；不凑槽位、不混旧角色。需重画用imagegen，既有图集拆格和透明视频转换用FFmpeg。本轮R3横幅复用既有静态图集，没有生成新角色。
3. **用可测媒体迭代。** A2从A1处理alpha边缘，原RGB主体/时序保持；记录尺寸、帧数、时长、透明度、字节、SHA、来源，以约180px白/深背景及实际窗口判断。脚底一次固定偏移校准，保留0.5.1裁切反例，不建立逐帧锚点体系。
4. **主题先走开放token。** 暖白/夜间色对和原创网格继承原设计；用官方Session合成正文/代码/表格/工具与真实输入/菜单检查。宿主缺少专用token的语法/链接限制如实记录，不铺私有CSS或移植自绘聊天布局。
5. **开场复用已有稿与启动器。** HTML/CSS档案底板经CUA渲染poster，原扫描去音轨，统一为1280×720 WebM；实测205帧/25fps/8.20秒。原MP4/旧NOTICE保持，0.7.1前导caption为“就绪后进入”。先核对同一播放场景：R3初始“欢迎回来。”与播放archive态“翻开今天的档案。”不同。本轮沿用0.7.1全部媒体，没有制作或采用0.7.2；修的是原生展示壳，不另造时间轴/声音系统。
6. **声明、校验、按身份试接。** manifest只放资源和模块数据；字段/默认由实际合同解析，已有loader验证路径/摘要/默认。FFmpeg/Pillow用于测量与编码；CUA隔离试接和主控真实DSH操作各自记录，旧报告不能替新身份验收。
7. **普通内置与产品版式同时核对。** 设计目录是本套唯一参数输入，构建同步至packages/dsh-companion/skins/archive-warm-whale，运行不依赖设计目录。M7曾核对内置入口/可用性，遗漏了R3版式还原，本轮按真实反馈补齐：常用三项/更多五项、同角色横幅、固定页签与底栏、分隔行、默认/自定义、模块关闭收起；custom开场采用单张16:9主画面、右上进入、底部细进度，原Host就绪/结束逻辑保留。支持才显示，模拟字段不跟着视觉还原进入运行合同。
