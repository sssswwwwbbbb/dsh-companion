## 视觉依据

沿用已选 LeeRolling/dsh-boot-suite 固定提交 34b892eae168abf14fc9623cb109d6806ffeacf2 的档案暖白与扫描角色方向。archive-warm 的强调色 #FF7500 由沈宏宏原作、LeeRolling 维护。本轮只提取色彩职责和档案叙事，不移植其五步“授权/核验”文案，以免开场装饰被理解为真实权限操作。

日常工作页采用安静的档案纸面：暖灰底板、不透明正文、细分隔线、适量展示衬线。橙色负责操作与选中，蓝色负责角色和状态。具体样式属于本套，不作为底座的硬编码规则。

## 文字、间距与组件

- UI：-apple-system / SF Pro Text / PingFang SC / Noto Sans SC / sans-serif，13–15px。正文 15px、行高 1.85；小窗口正文 14px。
- 展示：Iowan Old Style / Baskerville / Songti SC / Noto Serif SC，普通标题 25–30px，开场 28–52px。只用于短标题，不用于长正文、工具记录与代码。
- 代码：SFMono-Regular / Menlo / Consolas / monospace，12px、行高 1.8；长行局部滚动。
- 4px 间距单位：4 / 8 / 12 / 16 / 24 / 32。正文列最大 760px；桌面侧栏参考官方 264px 最小值。
- 常规控件圆角 6px、输入 14px、窗口 18px。对话与设置以留白和分隔线组织，不给每个项目加卡片。
- 图标使用统一 24 单位线框、1.55px 笔画，仅做语义符号；不替换官方品牌。
- hover 140ms，面板 220ms。focus-visible 2px 外描边 + 3px 间隔。禁用状态保留原因，不能只变灰。

## 阅读保护

自带原创网格背景留出中央静区。正文、代码、表格、菜单与输入始终使用不透明稳定表面。复杂背景压力场景仅用于验证静区策略，不是新增外部壁纸能力。

聊天记录单独滚动，输入区常驻。宽表格和长代码自行横向滚动。文件预览可关闭；小窗口缩减侧栏，极窄时文件预览占满内容区域。对应宿主的实际三栏让位逻辑仍由底座/官方布局维护，不把模拟 CSS 当宿主替换代码。

## 动态与恢复

默认跟随系统减少动态；显式减少动态使用静态待机帧、跳过扫描、停用自动视频和脉冲，保留状态文字。停止效果清空待播时序，使用中性预览颜色；恢复只回待机。设置重置保留全局停止意图。

实际合同暂未提供减少动态或新扫描模块。内容包不写入这些字段；需要该能力时先关闭可选桌宠，待模块补齐再接入。管理页在当前底座中恢复宿主外观，不能把本次设置视觉稿宣称为已接入页面。
