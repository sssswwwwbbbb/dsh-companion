# 互动时序与配置显示 / R2

2026-11-03。R2 使用统一角色四姿态和 CSS 轻动态演示；实际内容包仍为 R1 技术验证包，未包含 R2 角色。

## 共同规则

单角色同一时刻只播一个动作；同一气泡最多一条。优先级：全部停止/模块不可用 > 需要用户处理 > 任务完成 > 主动点击 > 待机。用户暂停随时生效，旧回调不能重新显现。所有事件只跟随当前可见会话，后台任务不抢占。

没有声音资源进入默认行为；不逐 token 更新动作，不读取输入内容、不增加全局键盘监听。原型对话与状态仅由页面按钮模拟。

## I01 点击回应

| 时点 | 动作与反馈 |
|---|---|
| 点击 | 若启用且可用，idle → react；气泡“嗯，我在。” |
| 同一回应期间再次点击 | 合并，不重新开始当前回应、不堆队列 |
| 1.8 秒 | 回 idle，气泡一起撤下 |
| 完成 / 需处理 / 停止 | 高优先级立即接管；不补播被中断动作 |
| 减少动态 | 静态待机 + 气泡，4 秒后结束 |

当前 react 是统一角色的静态姿态及整体侧倾演示，不冒充新制作的逐帧短片。greet 挥手姿态保留 2.6 秒，stretch 保留 3 秒；动作结束返回同一图集的 idle。完整动作的肢体运动、出入姿态仍待制作验收。

## I03 任务结果反馈

| 事件 | 默认处理 | 互斥 / 冷却 |
|---|---|---|
| 正在运行 | idle，无额外每字动画 | 不抢占点击 |
| 成功完成 | greet 一次，气泡“这件事，做好了。” | 30 秒最短间隔，重复合并；默认无声音 |
| 失败 / 取消 | 不庆祝；状态保留在会话 | 不借成功动画表示失败 |
| 需要用户处理 | 立即取消庆祝，静态待机 + 提示回会话 | 优先于完成/点击；不代办原始业务操作 |
| 全部停止 | 清理动作和气泡 | 不缓存重播 |

可调默认：completion=true、bubbles=true、cooldown=30（15/30/60）、completionAction=greet（greet/stretch）。动作选择只在本轮四姿态设计中选择，不发明模型专属角色。真实事件源、去重键、会话切换与桥接尚未接入；这些设置只在原型显示“设计提案 · 模拟状态”，不进入实际 manifest。

## 开场衔接

1. 档案底板 1.2 秒，文案“翻开今天的档案”，不冒充授权检查。
2. 扫描原片 7.04 秒，无声、contain、窗口内播放，不全屏铺满系统桌面。
3. 交给工作区，角色待机。按钮/ESC 可立即跳过；模拟总时长上限 8.24 秒，不阻断真实应用加载。
4. 停止、开场关闭、减少动态直接使用静态工作区。运行中恢复效果不自动重播。

这个演示不是宿主冷启动测试。正式冷启动沿用 dev.11 既有规则；新扫描模块由底座后续开放。

## 默认值与显示规则

机器可读设计值：designs/dsh-skin-v1/content/design-defaults.json。每个公开字段都有 default 和合法范围。历史 R1 内容包只公开 backgroundOpacity=0.04、pet.size=100，其余运行参数固定或沿用现有行为；该包不代表 R2 角色已完成接入。

| 情况 | 界面表现 | 参数处理 |
|---|---|---|
| 默认 | “默认” | 本套默认 |
| 自定义 | “已自定义” | 本套局部覆写 |
| 用户关闭 | 开关保留，子项收起 | 子项数值保留 |
| 能力不可用 | 原因 + 禁用开关 | 不当作用户关闭 |
| 当前皮肤未声明 | 隐藏控件与导航入口 | 不运行，不继承另一皮肤值 |
| 重置本套 | 确认后回默认 | 全局停止、静音、授权不清除 |
| 保存失败 | 明示仅本次有效 | 不声称已持久化 |

原型“默认/自定义/关闭/不可用/未声明”按钮为审稿控制，不进入正式产品。实际 settings 页必须从底座解析结果生成；不能直接搬运全部模拟字段。
