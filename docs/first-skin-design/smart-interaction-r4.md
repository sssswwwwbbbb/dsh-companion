## 连续互动和打断

输入 → 当前人设/情景/近期实际结果/可用能力 → 模型选择短句、姿态或安静 → 现有本地执行链 → 结果回到下一轮。原型为这条链展示固定样例，历史中的来源明确标为 fixture/local/fallback。

- 等待中停止：取消当前样例，保持停止；恢复不补播旧回应。
- 等待中关闭能力：返回后按当前能力呈现，关闭说话就不展示短句，关闭动作就不执行所选姿态。
- 切回本地：取消等待中的样例，使用本地回应。
- 失败：简短本地回退，并把回退实际姿态作为下一轮记录。
- 记忆 0：上下文为空，屏幕记录仍保留。清除演示记录只操作本页独立的 localStorage 键。
- 刷新：保留人设、模式、历史轮数、能力设置、停止状态和完成/取消记录；不自动重发请求。
