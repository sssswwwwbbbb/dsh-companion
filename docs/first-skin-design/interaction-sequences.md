# 互动状态与可配置规则 / R3

2026-11-03，回应独立反例。仅本地设计模拟，没有真实会话事件、模型读取或原生桌面操作。

## 独立状态

- 能力可用、用户启用意图、全局停止、原会话处理状态分别记录。有效表演优先级为停止/不可用/用户关闭 → 需处理静态状态 → 完成反馈 → 点击 → 自主姿态 → idle。
- Settings 与 Flow 使用同一有效状态。能力缺失移除可点击/活动角色，说明原因并保留参数；恢复能力不改变用户关闭意图。静态角色审稿区可保留，须标明仅审稿。
- needs-user 是持续状态，不从气泡文字推断。可选气泡、完成反馈或桌宠处理提示的开关不清原会话事项。固定提示保留，角色冻结为 idle，直到“模拟已处理”或显式切换示例会话。
- 停止清空待播动作与气泡，不代替用户处理事项。恢复不重播开场；若原事项尚在仍静态。回待机只结束表演，不消除原会话状态。

## 点击、完成及自主姿态

| 触发 | 默认 | 可调内容 | 当前实现边界 |
|---|---|---|---|
| 点击 | react / 1.8s / 嗯，我在。/ 冷却 2s | 动作 react/greet/idle、纯文本 ≤40字、0–10s 冷却、可选气泡 | 本地姿态/CSS；动作中重复点击合并，冷却中忽略。 |
| 完成 | greet / 2.6s / 这件事，做好了。/ 冷却30s | greet/stretch/idle、纯文本 ≤60字、5–300s 冷却、专属规则 | 仅当前可见示例会话；需处理优先，不借庆祝表示失败。 |
| 需要处理 | 静态 idle + 固定提示；气泡可选 | 可选短句 ≤60字、是否显示桌宠气泡提示 | 状态独立于气泡，任务未解除前不恢复呼吸。 |
| 自主活动 | 默认关闭 | profile、活动开关、30/60/90s 间隔 | 只在 Flow、能力可用、未停止/减少动态/待处理时调度现有姿态。不逐帧调用模型。 |
| 鼠标跟随 | 默认关闭 | 开/关 | 仅演示框内轻微位移；原生跟随不计本轮已验。 |

普通姿态结束回同角色 idle；react=1.8s、greet=2.6s、stretch=3s；减少动态的点击/完成文字最多保留4s。需要处理不会因这4s期限解除。纯空白文案不生成气泡。

## 映射编辑与回退

总开关默认关闭，保留一条 DeepSeek 示例模型完成→stretch 的可编辑样例。最多8条，精确模型优先于任意模型，再回本套默认；关闭的规则忽略并保留。相同模型与事件只允许一条启用规则。

事件仅 completed / needs-user 两种样例；needs-user 动作强制 idle。UI 不提供不存在的角色/服装变体，不接受脚本、模板或任意外部资源。模型 ID 是 example-deepseek / example-other / *，不冒充真实宿主 ID。

手动测试规则会进入 Flow 并按所选示例模型预演，仍服从需处理优先级和停止/不可用。切换示例会话/模型清旧反馈、点击和完成冷却；规则继续留在当前皮肤覆写中。
