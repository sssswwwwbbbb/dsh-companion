# 无桌宠主题 · 全量素材清单

供 UI、美术、动效、音频和文案人员直接执行。状态「运行」表示可由 1.0 已有接口消费；「源稿」是制作交接；「规划」须先与引擎线确认。尺寸中“建议”是制作起点，项目确认后统一，不等同于硬编码限制。

## 1. 必需与基础材料

| 编号 | 要做什么 | 交付内容与建议规格 | 数量/用途 | 接入 |
| --- | --- | --- | --- | --- |
| A01 | 主题与角色识别板 | 一页主题名、角色名、世界观、主辅色、标志物和风格参考；角色全身正面+面部细节，源稿分层 | 1 套，保证开场/界面/桌宠是同一角色 | 源稿 |
| A02 | 明暗工作区稿 | 浅/深各一张真实比例工作区图；含目录、会话、正文、代码块、表格、输入框、模型菜单、选中/悬停/禁用/错误 | 至少 2 张主稿与关键状态局部稿 | 源稿/验收 |
| A03 | 明暗色板 | 文字、弱文字、底色、层级表面、线框、悬停、选中、输入、链接、代码、成功/警告/错误；按 theme-tokens.json 写明暗值 | 1 张完整表，颜色人员与开发共同映射 | 运行 |
| A04 | 主题盒子入口徽记 | 96×96 透明 PNG，light/dark 各一张；源文件可交 SVG，按真实 16/20/24px 查清晰度 | 2 张；与普通功能图标分开 | 运行 |
| A05 | 皮肤库封面 | 建议 960×600、16:10 PNG/WebP，≤2 MiB；文字留安全边距 | 1 张，显示皮肤名称/角色主视觉 | 运行 |
| A06 | 开场静帧 | 建议 1280×720 PNG/WebP，与成片同角色、构图与色调；静帧单独也能成立 | 1 张，减少动态/解码失败时使用 | 运行 |
| A07 | 开场影片 | 1280×720 H.264/AAC MP4，建议 5–12 秒，实际 1–15 秒；单文件 ≤16 MiB；交真实时长 | 1 条，声画完整，不切掉结尾 | 运行 |
| A08 | 默认文案与角色设定 | 主题名、角色名、用户称呼、开场问候/字幕、默认语气、身份设定、正常/报错/详细解释示例；带桌宠再交桌宠场景补充和本地回退短句 | 1 份 Markdown，字段字数见开发说明 | 运行/源稿 |
| A09 | 来源与许可台账 | 按资源 ID 逐件记作者、来源、修改范围、署名、可用于何处、能否再分发；字体/图像/配音/音乐分别登记 | 1 份表 + 许可附件 | 交付 |

无桌宠版不制作桌宠动作、命中数据和物理交互素材。A01 仍可有角色主视觉，也可选择纯场景世界观。

## 3. 音频与字幕：即使无桌宠也要列入交付

| 编号 | 声音材料 | 文件与制作要求 | 如何使用 |
| --- | --- | --- | --- |
| S01 | 角色音色与配音 | 音色方向/试音、逐句干声 WAV、台词文本、每句 ID；48 kHz/24-bit 立体声可直接作为源轨 | 选中的开场语音混入 MP4；独立事件播音仍为规划 |
| S02 | 开场音效 | 上电/扫描/触碰/转场等分轨 WAV，写触发时间点；可复用同一声音 | 混入开场音轨 |
| S03 | 音乐与氛围 | 音乐、环境声分轨 WAV，附循环点（若有）与许可；配音和音乐分开交 | 形成同场景声音语言，开场采用混合成片 |
| S04 | 最终混音 | 有声 MP4、最终 WAV、配音/音效/音乐/氛围分轨；源轨约 −16 LUFS-I，真峰值 ≤−1 dBTP，按实际试听调整 | 无需额外静音运行 MP4，开关会静音原片 |
| S05 | 字幕和声音事件表 | 每句台词的 ID、文本、起止时间、关联画面；引擎当前内置字幕以 opening greeting/subtitle 为准；其他逐句字幕可直接烧入影片 | 同时交无字幕母片作为源稿可选，运行片按确认方案 |
| S06 | 事件音/预录短句储备 | 仅做已确认场景，源 WAV 单条 ≤2秒，48 kHz/24-bit/立体声、−16 LUFS-I、真峰值 ≤−1 dBTP；<400ms 点击音以峰值及同组试听校准 | 规划素材，1.0 尚无独立事件音/预录语音通用播放字段；无需自行转 WebM |

不做声音的主题应在任务单标明 S01–S04 不制作，开场交无音轨 MP4；不以空文件占位。字体若采用第三方，交字体名与许可；现行通用包使用宿主字体，不要求制作人员交未经接入的字库文件。

## 4. 导出和对齐验收

PNG/WebP 用 sRGB。图标、徽记和桌宠帧保留真实透明边缘，浅底、深底都查黑白边。影片不靠拉伸适配窗口。发送/停止图标要同时在浅底、深色按钮底、禁用低透明度状态下可见。每段交尺寸、帧率、帧数、实际时长与循环说明。源文件保留可编辑分层；无需强求 AE/Lottie 等制作方没有的工程。

## 5. 素材包应长这样

```text
skin-materials/
  review/        # 角色板、明暗工作区稿、分镜、三场景提示示意
  source/        # 图像分层、原始帧、开场剪辑、音频工程或分轨
  exports/       # 开发可直接用的图片、图标、MP4；桌宠另有透明帧/转好的 WebM
  audio/voice/   # 逐句干声
  audio/fx/      # 音效
  audio/music/   # 音乐与环境
  audio/mix/     # 最终混音
  copy/          # 人设、语气、短句、字幕
  registers/     # 资产表、声音表、动作目录
  licenses/      # 各项来源、授权与署名
```

每件填写 asset-register.csv；音频另填 audio-cues.csv；动作另填 action-catalog.csv。运行素材与源稿分目录，源稿不会直接塞进皮肤 ZIP。更多小巧思和后续功能见 materials-optional.md。
