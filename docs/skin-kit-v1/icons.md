# 主题盒子 1.0 · 图标逐枚清单

## 功能图标清单 导航与对话

当前可接入 50 枚工作区图标和 1 枚独立主题盒子入口徽记。其余 5 枚归入待接入素材。矢量用 24×24 画板，PNG 为 96×96 px、sRGB、RGBA。按 16、20、24 px 实际显示尺寸检查识别度，保持同组的线宽、光学居中和留白。

以 send 为例，交 `source/icons/send.svg`、`exports/icons/light/send.png` 和 `exports/icons/dark/send.png`。浅深两版共用轮廓，并在各自背景上调整颜色。

† 标注独立入口或待接入项。主题盒子入口单独走 `entryMarks`。历史、书签、引用、音量、静音当前不计入首轮必交。

套图交付前逐一核对名称、形状和明暗两份成品。发送与停止、打开与收起、播放与暂停、声音与静音应能一眼分开。


发送/停止要在浅背景、深色按钮底、禁用低透明度三种状态验收。`more`、`send`、`stop`、`plus`、`model`、`file-code` 在少量上下文仍保留宿主原图，不能把交付图标数量当作所有位置已替换。当前 50 个工作区键与独立入口徽记先做；history/bookmark/quote/volume/mute 为储备。
