# 机械姬桌宠约稿需求清单

2026-11-05。给画师的委托需求与验收清单。用途：把「我想要一个机械姬」变成可报价、可验收、可追责的委托。

## 0. 先定四件事

不定这四件，报价没有意义，后面必吵。

| 项 | 选项 | 影响 |
| --- | --- | --- |
| 用途 | 自用 / 商用售卖 / 商用但免费发布 | 决定授权范围与价格倍数 |
| 交付物 | 设定图 / 分层立绘 / 动作 / UI | 决定找画师还是画师+动画师 |
| 风格 | 科研企业风（已定） | 决定参考图与禁区 |
| 预算与时间 | 分几批、多久 | 决定付款节奏 |

## 1. 交付物清单

按批次发，不要一次全给。每批验收通过再进下一批。

| 批次 | 交付物 | 数量 | 格式 |
| --- | --- | --- | --- |
| A 设定 | 全身母版 | 1 | PSD（分层）+ PNG（透明） |
| A 设定 | 三视图（正/侧/背） | 1 套 | PSD + PNG |
| A 设定 | 表情表（观测窗 6 态） | 1 套 | PSD（每态独立图层） |
| A 设定 | 色卡与材质说明 | 1 | PNG + 文字 |
| B 分层 | 立绘拆件（头/身/四肢/机械件/发光件） | 1 套 | PSD，图层不合并 |
| C 动作 | 8 段动作（见第 3 节） | 8 | PNG 序列 或 Live2D 参数 |
| D 道具 | 书、杯、坐垫、充电线 | 4 | PNG 透明 |
| D 界面 | 图标 16–40 枚、开场海报 | 1 套 | SVG / PNG |

## 2. 规格表（写进合同，别口头说）

- 画布：母版 2048×3072（或与现有 1664×2496 一致），全身入画不裁切。
- 色彩：sRGB、8bit。
- 透明：PNG 四角 alpha 必须为 0，发丝边缘不得有白边。
- 图层：按部件命名（`head` / `visor` / `arm_l` / `panel_chest` / `glow_chest`），**禁止合并图层**。
- 脚线：在 PSD 里标出脚底 y 坐标。
- 动作：24fps，单段 2–4 秒，循环动作首末帧姿态一致。
- 命名：`unit-07_idle_01.png`、`unit-07_react_01.png`。
- 源文件：PSD 必须交付，不接受只有 JPG/合成图。

## 3. 动作清单（C 批）

| id | 内容 | 时长 | 循环 |
| --- | --- | --- | --- |
| idle | 待机呼吸 | 2.5s | 是 |
| look | 东张西望 | 3s | 是 |
| walk | 走路 | 1s/循环 | 是 |
| run | 小跑 | 0.72s/循环 | 是 |
| react | 被点击回应 | 1.8s | 否 |
| greet | 打招呼 | 2.6s | 否 |
| drag | 被拎起悬空 | 循环 | 是 |
| land | 落地站稳 | 0.8s | 否 |

## 4. 角色设计要求

**必须清晰的三点**（每次都要画对，不是可选项）：

1. 观测窗的横向比例与两端收角。
2. 胸口纵向开孔与内部结构。
3. 左肩工牌带。

**机械姬特有的四条**：

- 关节、装甲、天线、发光件必须**单独图层**，后续要绑定或程序驱动。
- 发光件用叠加层，颜色 `#56D6E0`，面积不超过一成。
- 机械结构要合理：关节有转轴，装甲有厚度，不做贴片。
- 脚是设备支脚，不是高跟鞋。

**禁止项**：战斗损伤、外挂武器、发光符文、紫粉渐变、彩虹霓虹、金色描边、大面积半透明。

## 5. 一致性要求

- 以母版为**唯一**参考，不自由发挥脸型、发型、配色比例。
- 三视图与母版同比例、同脚线。
- 所有表情基于同一张脸，不重画五官结构。
- 动作不改变人物大小，不跳框。

## 6. 授权与合同（最容易被忽略，也最容易吃亏）

| 条款 | 要写清什么 |
| --- | --- |
| 使用范围 | 线上/线下、期限、地域、是否独家 |
| 商用买断 | 是否买断、买断价是否另计 |
| 二次修改 | 你是否可以改色、改动作、裁切 |
| 源文件 | PSD/AI 是否交付，交付后你是否可再编辑 |
| AI 使用 | 是否允许 AI 辅助，必须书面写明 |
| 署名 | 是否要求署名、署名形式 |
| 修改次数 | 草图 2 次、线稿 1 次、上色 1 次，超出另计 |
| 付款 | 建议 30% 定金 / 40% 中期 / 30% 尾款 |
| 违约 | 延期、弃稿、退款规则 |

## 7. 验收清单（收到文件先查这 10 条）

1. 尺寸、色彩模式对不对。
2. 四角 alpha 是否为 0。
3. 图层有没有被合并。
4. 发丝、边缘有没有白边。
5. 三个识别点在 64px 缩略图下还能不能认出来。
6. 三视图比例是否一致。
7. 脚线位置是否标出。
8. 发光件是否独立成层。
9. 色值与色卡是否一致。
10. 文件名是否与清单一致。

## 8. 常见的坑

- 只给 JPG 合成图，不给 PSD。
- 图层合并，无法做动画。
- 「透明底」其实是白底。
- 每张像不同的人（风格漂移）。
- AI 图冒充手绘：线条抖动、结构错误、手指和关节数量不对。
- 授权写「仅个人使用」，却准备拿去卖。
- 尾款一次付完，人找不到。
- 修改次数没写死，无限返工或无限加价。

## 9. 可直接复制给画师的需求文本

> 你好，想约一套原创机械少女的桌宠素材，风格是「科研企业」：冷白 + 石墨 + 青色发光，干净、克制、无战斗损伤，像实验室设备而不是战斗机器人。原创角色，不参考任何现有游戏角色。
>
> 需要交付：
> 1. 角色母版 1 张：全身正面站姿，2048×3072，透明底 PNG + 分层 PSD，图层按部件命名、不合并。
> 2. 三视图：正面/侧面/背面，与母版同比例。
> 3. 表情表：观测窗 6 态（待机/注意/记录/困惑/低电/故障），每态独立图层。
> 4. 动作 8 段：待机呼吸、张望、走路、小跑、被点击回应、打招呼、拖拽悬空、落地站稳。24fps，2–4 秒，透明底。
> 5. 道具 4 件：书、杯、坐垫、充电线，各 1 张透明 PNG。
> 6. 开场海报 1 张：1920×1080。
>
> 硬性要求：
> - 三个识别点必须清晰：观测窗横向比例、胸口纵向开孔、左肩工牌带。
> - 机械关节、天线、发光件单独图层，后续要绑定动画。
> - 发光件用叠加层，`#56D6E0`，面积不超过一成。
> - 主色：暖白 `#F1F2EF`、冷灰 `#C7CDD2`、石墨 `#2B3138`、琥珀 `#E08A3C`（仅警示）。
> - 禁止：紫粉渐变、彩虹霓虹、金色描边、战斗损伤、外挂武器。

> 授权与流程：
> - 商用买断，含二次修改权与源文件。
> - 分四批交付，草图确认后再上色。
> - 修改：草图 2 次、线稿 1 次、上色 1 次。
> - 付款：30% 定金 / 40% 中期 / 30% 尾款。
>
> 请先报：单张价、整套价、周期，以及是否接受 AI 辅助（需在合同中写明）。

## 10. 自用版：交付物与授权怎么改

用途改为个人自用后，清单可以砍掉一半，但有三样不能砍。

### 10.1 交付物是什么

一句话：**你付钱之后实际拿到手的文件清单**。写清四件事——数量、格式、尺寸、分不分层。不写，画师默认交一张 JPG。

例：不要写「画一个机械姬」，要写「1 张 2048×3072 透明底 PNG + 同尺寸分层 PSD，图层按部件命名、不合并」。

### 10.2 自用版清单

| 优先级 | 交付物 | 数量 | 格式 | 作用 |
| --- | --- | --- | --- | --- |
| 必须 | 角色母版 | 1 张 | 分层 PSD + 透明 PNG | 所有动作的参考源 |
| 必须 | 侧面图 | 1 张 | PSD + PNG | 走路、侧躺、攀爬 |
| 必须 | 动作 4 段 | idle / look / walk / react | PNG 序列 | 桌宠最小可用集 |
| 建议 | 动作 4 段 | run / greet / drag / land | PNG 序列 | 有了才像活的 |
| 建议 | 观测窗表情 | 3–6 态 | PSD 分层 | 情绪最便宜的做法 |
| 可选 | 道具 | 书、杯、垫、充电线 | PNG 透明 | 二期 |
| 可选 | 开场海报 | 1 张 | PNG 1920×1080 | 主题要用，可最后补 |

三个不能省：**分层 PSD**（要改色拆件）、**PNG 序列**（视频改不了循环与接缝）、**侧面图**（省了走路只能脑补）。

### 10.3 自用版授权

| 条款 | 自用怎么写 |
| --- | --- |
| 使用范围 | 个人使用，不商用、不转售 |
| 修改权 | 允许本人修改、裁切、改色 |
| 源文件 | 交付 PSD |
| AI 辅助 | 书面写明允许与否 |
| 署名 | 非必需 |
| 独家 | 不需要 |

自用不用买断，价格低很多；但「能不能改」与「给不给源文件」必须谈，否则拿到手也动不了。

### 10.4 自用版需求文本

> 想约一个原创机械少女，个人自用。需要：1 张全身母版（2048×3072，透明 PNG + 分层 PSD，图层不合并）；1 张侧面图（同规格）；4 段动作（待机、张望、走路、被点击回应，PNG 序列，24fps，2–4 秒，循环首末帧姿态一致）。风格是科研企业风：冷白 + 石墨 + 青色发光（#56D6E0），干净克制，无战斗损伤，不参考现有游戏角色。请报单张价和整套价，以及能否交付分层源文件。
