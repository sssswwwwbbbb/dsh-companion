# DSH 第二套皮肤全量素材清单与委托单

> 2026-11-08 最新版开发说明与素材清单见 [主题盒子 1.0 交接包](skin-kit-v1/README.md)。下文保留旧制作记录，版本与能力以最新版为准。


供角色原画、界面视觉、动效、配音、声音设计、文案及开发人员使用。主题名、角色、题材和参考图由项目方确认。两种主题都包含工作区视觉、开场、声音和文案。桌宠版另外制作桌面角色的动作与互动。无桌宠版可以在开场、封面和工作区中使用角色立绘或场景主视觉。

各工种的交付汇总为一个独立素材包，包含可编辑工程、运行成品、文案及来源。开发者接收后负责录入皮肤配置、校验与打包。每个版本的基础素材、可选增强以及需要引擎接入的项目分别标明。

对外使用独立的 [带桌宠版素材清单](second-skin-materials-with-pet.pdf) 或 [无桌宠版素材清单](second-skin-materials-without-pet.pdf)。两份都包含完整的功能图标明细和可选增强项。

## 1. 首轮必做

| 编号 | 交给美术的任务 | 数量与规格 | 对应配置或用途 |
| --- | --- | --- | --- |
| A01 | 角色设定与立绘 | 1 张全身正面分层母版，头饰、全身和鞋尖入画。附角色配色、发色瞳色、服装细节、表情和姿态参考。建议保留长边 2048 px 以上源稿 | 开场、桌宠及可选工作区头像的共同设计母版 |
| A02 | 工作区视觉与明暗色板 | 2 张同构图关键稿，一深一浅。覆盖侧栏与目录、会话正文、代码/表格、输入和选中状态。附背景、层次、文字、边框、强调、成功、警告和错误色的 HEX 值 | `theme.config.tokens`，开发者映射到 DSH 现有语义色 |
| A03 | 桌宠待机 | 1 段透明 WebM，建议 2–4 秒。轻微呼吸、眨眼或安静待命。首尾可循环，第一帧单独停住也自然。另交代表静帧和脚点 | 资源 ID `role-idle` → `pet.config.animations.idle` |
| A04 | 桌宠回应 | 1 段透明 WebM，建议 1–2 秒。表现一个读得懂的动作，如抬头、点头或轻微挥手。结束回到可衔接待机的姿态 | `role-react` → `pet.config.animations.react` |
| A05 | 开场静帧 | 1 张 PNG，建议 1280×720、16:9。与开场正片同角色，可独立用作静态版本 | `opening-still` → `startup.config.poster` |
| A06 | 开场成片 | 1 段 16:9 短片，建议 1280×720、5–12 秒。先交首尾和短分镜，定稿交 MP4 或 WebM。最后一幕便于自然切回工作区。若本轮包含声音，成片带混音，另交分轨 | `opening-film` → `startup.config.video`，实测时长填 `startup.config.seconds` |
| A07 | 基础文案 | 主题名、角色名与型号、用户称呼、开场标题与副标题，以及一条可选的桌宠回应。附角色语气和称呼规则 | `name`、`description`、`startup.config.greeting`、`startup.config.subtitle`，有对应互动时可填 `pet.config.localReply` |

首轮的运行素材是两段透明动作、一张开场静帧和一段开场成片。角色母版和工作区关键稿属于设计交付，开发者按需导出运行资产。待机、回应和开场角色保持一致的脸、发色、头饰、服装与鞋型。为人物全身预留活动余量，避免动作出框。建议在开场、工作区、桌宠三个尺寸上放一张并排对照稿。

## 3. 声音素材

开场声音可直接随成片接入。按本套选择配音、音效、音乐和环境声，各自交分轨，最后再交成片混音。工作区和桌宠的独立声音先按配置能力选择，涉及新触发点时由开发者确认。

| 编号 | 声音素材 | 应交文件 | 用途与接入 |
| --- | --- | --- | --- |
| S01 | 配音试音与正式台词 | 角色音色参考、试音、逐句台词和干声 WAV，文件名对应台词 ID。交字幕文字与时间码 | 开场旁白、角色开口、就绪提示。最终选用的声音混入开场影片 |
| S02 | 开场音效 | 按分镜交独立 WAV 和时间点，例如上电、扫描、机械动作、转场、结束落点 | 对应开场画面节点，混入影片音轨 |
| S03 | 开场氛围与音乐 | 环境底声、音乐及许可，若需循环另标循环点。配音、音乐、环境音和音效分别成轨 | 与开场声画统一，保留无对白版或按需拆混 |
| S04 | 最终开场混音 | 有声正片、无声审看版、最终 WAV 和各分轨。推荐保留 48 kHz / 24-bit WAV 源轨。交一份时间点表 | 游戏式声画体验由一条影片音轨交付，`startup.settings.soundEnabled` 控制声音。减少动态以静帧验收 |
| S05 | 桌宠互动声音候选 | 点击、被拖起、落地、回应、打招呼、工作状态等实际入选场景的短音效或预录短句。交每条触发点和静音表现 | dev.27 可配置的是桌宠短句输出与开场音轨。预录短句或桌宠独立音效按事件播放需引擎接入 |
| S06 | 工作区声音候选 | 成功、需要处理、轻量彩蛋、专注计时提醒等按入选场景交成品，附实际用法和触发冷却 | 作为独立增强，确认宿主事件及播放能力后接入 |

台词、配乐、音效各自记录创作者、来源、使用与再分发许可。配音及音色如需重用或二次剪辑，在委托时明确范围。保持短音效音量协调，实际 DSH 试听时确认台词清晰、切出时无残音，静音时视觉仍可理解。

## 4. 后续功能与素材对照

表里的首版遗留和互动候选沿用项目路线图。走跑、坐躺、攀爬、读书喝茶是「冷启动」的场景例子，第二套按自己的角色和世界观定动作、道具、反馈及声音。基础 ZIP 可使用第 1 节的素材。开发者确认入选场景的事件、动作和配置后，再做完整成品。同一动作、音效或文案可在多个场景复用，台账中用同一资源 ID 关联。[项目路线图](skin-roadmap-2026-11-06.md) · [原互动规划](skin-scope-and-interactions-2026-11-03.md)

| 后续功能 | 素材应准备到什么程度 | 委托和接入节点 |
| --- | --- | --- |
| 多方向走路、小跑和回待机 | 每个选定方向和速度交起步、循环、减速、停步或转正。附脚点、步幅和行进方向。需要脚步声时交可复用的单步音效及落脚时间点 | 首版遗留。优先做一条自然结束的路线，镜像、换向、位移和声音由开发确认 |
| 坐下、侧躺、休息、攀爬或窗口栖息 | 每个入选姿态交进入、保持、退出及被打断的衔接帧。攀爬另交接触边、手脚锚点和遮挡参考 | 首版遗留。窗口边缘行为按平台支持确认 |
| 读书、喝茶等道具互动 | 角色取出、使用、收回的动作。另交书杯透明分层、手部抓握点、遮挡层和出现/收起帧。翻页、轻碰等音效可单独交轨 | 首版遗留。先完整做一个道具场景，原生跟随和缩放由引擎确认 |
| 专注、待用户处理、完成反馈 | 每种状态各交一组静帧或短动作、状态图标、简短文案。入选提醒可另交一条短音效或语音。附静音和减少动态时可用的表现 | 首版遗留。现有开关可复用，动作映射、提醒频率和声音触发按事件逐项接入 |
| 模型自主选择动作、被打断与恢复 | 除动作主片，交动作目录，写清稳定 ID、行为含义、适合的场景、起始与结束姿态、道具、声音、打断和恢复片段。公共待机、收尾、回正可复用。打盹、伸懒腰、看向用户可按角色设计取舍 | 长期目标。模型根据可用素材与情境选动作或保持安静，开发者确认目录与本地执行器的映射 |
| 模型切换动作、模型对应形象 | 先交默认形象和一个变体试样，可只换徽标、服装局部或配色。拟启用完整换角色时，每个变体另配头像、待机、回应和对应文案。附切换过渡及提供方/模型到素材组的对照表 | 互动候选。默认形象可回退，事件和映射接口接入后再批量制作变体 |
| 回到 DSH、切会话或切工作区 | 回归招呼交可复用的抬头或挥手、短句及可选语音。操作过渡交简短动效、徽标或颜色表。按工作区换氛围时另交每组背景或配色、饰物及默认组 | 互动候选。确认触发、冷却及无声表现后选一项 |
| 输入陪伴、专注计时与休息提醒 | 输入陪伴交短暂看向用户或专注姿态及收尾。计时交开始、进行中、结束或休息的图标和文案，结束动作可复用伸懒腰，提示音单轨 | 互动候选。素材按触发样例制作，计时和静默设置由引擎负责 |
| 摸头、投喂、拖起落地与熟悉感 | 确定采用时再交对应表情、可选食物或装饰、拖起/落地动作及短句。熟悉感可从几组问候和一个小饰物起步 | 互动候选。先复用已支持的点击、拖动和回应入口 |
| 角色快捷动作与工作区细节 | 按入选菜单项交语义图标、按钮标签和操作结果文案。模型选择器、文件预览、工具控件、菜单和弹层交明暗稿及正常、悬停、焦点、禁用等实际状态 | 首版覆盖核对与快捷动作候选。开发先确认宿主可接入的位置，再定成品数量 |
| 主题人设与工作区回复风格 | 一份共用设定，另交「工作区回复风格」和「桌宠说话与行为」两组文案。工作区稿给普通工作问答、错误说明、要求展开等样例。桌宠稿给称呼、短句、动作语义及何时安静 | 首版遗留。首批产物可以是纯文本，主题提供默认风格，用户可调整。工作区提示词接入由引擎验证 |
| 创作者模板、插件内自制和上传 | 公共模板用可再分发的占位立绘、图标、静帧、基础动作和可选声音，附来源与许可。作者上传交作品封面、简介、版本及署名等展示资料 | 已确认后置。公共模板和具体皮肤成品分别管理 |
| Windows 适配 | 复用同一套开场、声音、图标、桌宠和文本。为验收保留一份标准素材和参考画面，供实际显示缩放、透明边缘及音轨对照 | 平台线负责实机适配。新增平台专用导出项由实测结果确定 |

桌宠版先交一段完整的「待机 → 入选动作 → 恢复待机」，再配一组工作状态的动作和静音文案。为入选互动另交一张映射表，包含触发场景、动作或图片 ID、音轨 ID、短句、静音/减少动态替代、结束和打断后的动作，供开发核对配置与验收。

模型自主动作的委托可先用以下表头。作者填写行为描述和素材，开发者补当前可执行条件与动作映射。

```csv
动作ID,行为描述,适合场景,起始姿态,动作素材ID,循环方式,结束姿态,道具ID,音轨ID,打断时如何收尾,后续可接动作
```

## 5. 导出与交接

- **透明媒体**。待机与回应使用相同画布和脚点，建议先交一段透明测试片，开发者在实际 Mac DSH 验清晰度、透明度和尺寸再批量制作。源稿可用 1920×1080 画布及 24/30 fps，成品以角色有效像素和运行体积为准。透明视频用真实 Alpha，在黑白背景检查边缘和残影。
- **开场与声音**。MP4 可先按 H.264、AAC 和快速起播导出。标注实测秒数和最后一个可见动作。正片自然结束与静音播放都要能看懂，静帧也可单独表达开场。台词或音效涉及第三方时逐件给来源与许可。
- **包体限制**。单张图片最多 8 MiB、单段视频最多 16 MiB，运行资源合计最多 128 MiB、最多 128 项。图标和视频的源工程留在素材包，运行 ZIP 只带实际声明使用的成品。
- **源文件**。提供所用软件可编辑工程，例如分层 PSD、KRA、CLIP、AE、剪辑工程或等价格式。注明版本、外部链接文件和字体。第三方字库、素材、配音、音效及 AI 素材如有，分别写明来源、允许的用途、署名及分发范围。
- **文件名与台账**。运行成品统一用英文小写和连字符。每件登记资源 ID、文件名、对应配置、规格、时长/帧率、Alpha、循环、脚点、作者、许可和可分发范围。交付时让目录、台账和实际文件一一对应。

## 6. 分三次交审

1. **定方向**。一页主题、角色母版草案、明暗色板、开场首尾和声音方向。若采用配音，先审角色试音与一句代表台词。
2. **验证一组素材**。交待机和回应短片、同一角色开场静帧与带参考声音的小样。开发者在 DSH 实装确认透明边缘、位置、脚点、文字可读性、静音和片尾交接。
3. **最终交付**。交独立素材 ZIP、可编辑工程、台词和声音分轨、台账及许可。项目方核对文件和各项委托范围。皮肤开发者再提交可导入的皮肤 ZIP 与实机测试结果。

## 7. 成套功能图标明细

全套设计规格为 **56 个功能位、56 枚矢量源稿、112 张浅深透明 PNG**。矢量以 24×24 画板为基准，PNG 统一 96×96 px、sRGB、RGBA。设计时分别以 16、20、24 px 检查笔画和识别度，统一留白、线宽与视觉中心。每个功能位沿用同一形状，以浅色和深色界面背景为基准调整配色。以 `send` 为例，交 `source/icons/send.svg`、`exports/icons/light/send.png` 和 `exports/icons/dark/send.png`。

## 8. 两个版本的工作区增强素材

小操作、执行过程、工作区待机和小演出在两个版本里都可以做。带桌宠版可以让角色配合动作，无桌宠版在工作区本身完成反馈。以下按实际选中的场景制作，每项交状态稿、动效源、运行导出、触发时机、结束画面和静态替代。采用独立声音时另交 WAV 与时间码，由开发确认事件及媒体接入。

| 可选场景 | 无桌宠版可做的画面 | 带桌宠版可追加的素材 |
| --- | --- | --- |
| 小操作 | 选新会话、发送、复制成功、切换模型、打开资料或切换工作区中的一项。交控件初态、短促反馈、终态，说明操作区域及可选声音 | 同步看向内容、点头、短句或角色徽记变化。交回应片段与恢复待机帧 |
| 执行中 | 交开始、执行中、需用户处理、完成、停止或失败的状态图标、文案和光效。过程可用低亮度脉冲或短循环，完成可用简短收尾 | 专注姿态、抬头提醒、完成动作，分别交静态替代或无声短句 |
| 工作区待机 | 在背景一角、品牌徽记或独立区域做低频小动画，例如局部亮点、慢速呼吸光、天气或环境变化。交静帧和低干扰循环 | 角色待机变体、伸展、变换姿态等，由本套角色决定。交进入、循环、退出和被打断的衔接 |
| 主题小演出 | 选一个明确触发，如用户主动预览、阶段完成或解锁彩蛋。交分镜、关键帧、前后场景、成片或透明叠层、混音及跳过后的落点 | 角色参与、道具出入、台词、表演结束后的待机姿态。把动作和声音放进同一时间点表 |

界面动效源可交 Figma 原型、AE 工程或逐帧序列。透明效果交带 Alpha 的素材，播放型演出可交视频。开发者依据确认的接入方式选择运行导出。静音时仍能看懂反馈，减少动态时保留文字与状态，业务操作结束后画面回到稳定状态。
