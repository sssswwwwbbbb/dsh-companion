# 主题盒子 · 使用说明（1.1.0）

这份说明给使用者，不含开发内容。三步就能用起来：安装 → 激活 → 导入皮肤。

## 1. 安装

**支持的平台**

- macOS ARM64（Apple 芯片）
- Windows x64
- DSH 0.2.1-rc.4、0.2.1-rc.5、0.2.2-rc.1

**下载地址**（由作者提供，无版本号，始终指向最新正式版）

- Mac：`https://<授权服务地址>/dsh-companion/install/dsh-companion-latest.tgz`
- Windows：`https://<授权服务地址>/dsh-companion/install/dsh-companion-latest-win32-x64.tgz`

**在 DSH 里安装**

1. 打开 DSH 的插件管理，点「添加插件」。
2. 把上面的链接粘贴到顶部的插件输入框。
3. 安装源选择「中国大陆镜像源」。链接不要填到「自定义地址」，那一栏是 npm registry。
4. 点安装并启用。装完后正常退出 DSH 再打开。

## 2. 激活

1. 侧栏进入「陪伴」→「开始使用」。
2. 找到「统一授权」，粘贴作者发给你的激活码。
3. 点「激活本机」。成功后显示「本机已授权」。

一份激活码有设备数量限制。换设备时先在「授权与更新」里解绑，再用原码绑定新机。

## 3. 导入皮肤

安装包本身不带皮肤，需要单独导入：

1. 侧栏「陪伴」→「皮肤库」。
2. 点「导入」，选择作者给你的 `.zip` 皮肤包。
3. 导入成功后点「应用皮肤」切换。

也可以在皮肤库里选中已安装的皮肤，点「本套设置」调整主题、开场与桌宠参数。

## 4. 日常使用

- **开局动画**：在皮肤设置里「预览开场」看效果；「启动时自动播放」控制打开 DSH 时是否播放。
- **桌宠**：在「桌宠控制」调整大小、行为与互动；支持皮肤的皮肤会把角色同步到桌宠。
- **更新**：「授权与更新」→「检查更新」，下载后按提示安装，授权和配置会保留。
- **停用**：用 DSH 官方插件开关停用，桌宠与动画停止；重新启用后授权和配置不变。

## 6. 出问题先看这里

- 激活失败：确认码完整、没有多余空格；已激活过其他码，先解绑。
- 导入失败：多半是 ZIP 不完整或根目录缺 `skin.json`，重新拿完整包。
- 没有开机动画：先确认已导入并应用皮肤，且「启用本套开场内容」是开的。
- 版本不匹配：皮肤只支持列出的 DSH 版本，升级 DSH 或换皮肤版本。
- 其他问题：见 [常见问题](常见问题.md)。
