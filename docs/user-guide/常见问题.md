# 常见问题

## 安装与启动

**装完没反应？**
装好后要完全退出 DSH（macOS 用 ⌘Q），再重新打开。插件在启动时接管桌面组件。

**提示版本不支持？**
插件、皮肤、DSH 三方都有版本要求。先看插件「授权与更新」里的兼容信息，再对照皮肤说明里的适配版本。

**Windows 托盘图标不对？**
确认用的是官方 Windows 包，不要用 Mac 包改名安装。

## 授权

**激活码提示无效？**
- 检查是否复制完整，前后没有空格。
- 每份码有设备数量上限，先解绑旧设备。
- 旧测试服务的码不能用于正式服务。

**换电脑怎么办？**
在原设备「授权与更新」→「解绑本机」，再在新设备用同一码激活。

**离线还能用吗？**
可以，但离线窗口有限；到期前联网刷新一次。

**授权到期/被停用？**
联系作者续期或恢复。停用后客户端下次联网校验会同步。

## 皮肤

**导入报「缺少 skin.json」？**
ZIP 根目录必须直接是 `skin.json` 和素材目录，不能再套一层文件夹。

**导入报资源摘要不一致？**
包被改动或下载不完整，重新获取原始 ZIP。

**提示「皮肤尚未支持当前 DSH」？**
换支持该 DSH 版本的皮肤版本，或先升级 DSH。

**想彻底移除一套皮肤？**
皮肤库中卸载即可；需要同时清空该皮肤设置时，选择一并清除设置。若本机还有同套的其他版本，需先全部卸载。

**开机动画不播放？**
- 未导入皮肤时不播放，这是预期行为。
- 检查「启用本套开场内容」与「启动时自动播放」是否都打开。
- 用「预览开场」验证资源是否完整。

## 更新与卸载

**怎么更新？**
「授权与更新」→「检查更新」→「下载更新」，再按提示在 DSH 插件管理里安装新包。授权与配置会保留。

**卸载会丢授权吗？**
不会。卸载或停用只移除插件与启动入口，授权和配置保存在独立目录，重装后恢复。

**启动入口没了？**
在「授权与更新」→「插件」里重新启用，或重建「陪伴启动器」。

## 隐私

- 启动动画与桌宠在本机运行。
- 授权请求只发送设备摘要与授权信息，不读取聊天内容、模型密钥或文件。
- 诊断信息只记录错误码与请求编号，不记录激活码。
