# 社区版：自己下载、自己用

开源用户走这条路径，不经过作者的授权服务器，也不消耗作者的带宽。

## 拿安装包

两种方式，任选：

**从 GitHub Releases 直接下**

到 <https://github.com/sssswwwwbbbb/dsh-companion/releases/latest>，下载：

- `dsh-plugin-companion-<版本>-community-darwin-arm64.tgz`（Mac）
- `dsh-plugin-companion-<版本>-community-win32-x64.tgz`（Windows）

**用仓库里的下载脚本**

```sh
node scripts/download-community.mjs darwin-arm64
node scripts/download-community.mjs win32-x64
```

脚本只访问 GitHub，不连接作者的服务端。

## 装进 DSH

在 DSH 插件管理里「添加插件」，选择下载到的 `.tgz` 文件安装。社区版免激活，不连接授权服务。

## 自带皮肤与自做皮肤

社区版自带三套皮肤，装完在「陪伴 → 皮肤库 → 自带皮肤」里直接应用：

- 冷启动 1.0.1
- 黑焰 0.2.4
- 决斗者 · 天空龙 1.1.0

想自己做皮肤，按作者指南做：

- 制作与交付：[docs/skin-kit-v1/developer-guide.md](../skin-kit-v1/developer-guide.md)
- 配置参考：[docs/skin-author-reference.md](../skin-author-reference.md)
- 校验工具：`node scripts/skin-author-check.mjs <你的.zip>`

做好后在主题盒子 → 皮肤库 → 导入即可。

## 想用官方皮肤

官方皮肤（冷启动、黑焰、天空龙）不随社区版分发，需向作者获取。

## 自己构建

不想用 Release 里的包，也可以本地构建：

```sh
node scripts/fetch-electron.mjs all
npm run package:mac
python3 experiments/dsh-windows-w1/build.py
```

构建产物默认是占位服务地址，不会包含作者的服务器信息。
