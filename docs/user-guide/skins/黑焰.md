# 黑焰（black-flame）

版本 **0.2.2** · 作者 Dr.S · 仅作者本人可分发

## 一句话

烬色与封存舱两套配色的工作区皮肤，配 9.4 秒立体声开场与回复风格。无桌宠版。

## 包含什么

| 模块 | 内容 |
| --- | --- |
| 主题 | 烬色、封存舱两套配色；50 枚中性色图标（明暗各一套）；入口徽记 |
| 开场 | 9.4 秒立体声开场，含合成音效与语音；静帧作过渡 |
| 回复风格 | 随皮肤启用 |

不含桌宠动作与主题角色，适合只想换工作区和开场的用户。

## 适配

- DSH：0.2.2-rc.1
- 平台：macOS ARM64、Windows x64
- 插件：主题盒子 1.0.0 及以上

## 安装

1. 主题盒子 → 皮肤库 → 导入，选择 `black-flame-0.2.2.zip`。
2. 点「应用皮肤」。
3. 「本套设置」里切换烬色 / 封存舱两套配色，调整开场音量与时长。

## 说明

- 开场为立体声，戴耳机效果更明显。
- 不支持更早的 DSH 版本，会提示 `SKIN_DSH_UNSUPPORTED`。
- 想关掉开场只保留主题：关闭「启用本套开场内容」。
