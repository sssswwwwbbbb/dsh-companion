# 决斗者 · 天空龙（duelist-sky-dragon）

版本 **1.0.7** · 作者 Dr.S · 仅作者本人可分发

## 一句话

决斗盘米白与夜空神卡两套配色的工作区皮肤，10 秒有声开场、场景提示与回复风格。无桌宠版。

## 包含什么

| 模块 | 内容 |
| --- | --- |
| 主题 | 决斗盘米白、夜空神卡两套配色；50 枚题材化图标（明暗各一套）；入口徽记 |
| 开场 | 10.08 秒有声开场，含语音与音效 |
| 场景提示 | 工作区事件提示的配色与文案随皮肤统一 |
| 回复风格 | 随皮肤启用，称呼与语气统一 |

不含桌宠动作与主题角色。

## 适配

- DSH：0.2.2-rc.1
- 平台：macOS ARM64、Windows x64
- 插件：主题盒子 1.1.0 及以上

## 安装

1. 主题盒子 → 皮肤库 → 导入，选择 `duelist-sky-dragon-1.0.7.zip`。
2. 点「应用皮肤」。
3. 「本套设置」里切换两套配色、开场开关与场景提示。

## 说明

- 1.0.7 为当前版本；同 id 新版本可直接下载更新，旧版设置保留。
- 开场有声音，静音环境可在设置里关闭。
- 只支持 DSH 0.2.2-rc.1，旧版会提示不兼容。
