# 冷启动（commander-workspace-private）

版本 **1.0.0** · 作者 Dr.S · 仅作者本人可分发

## 一句话

与指挥官协作的工作区皮肤：机械姬主题、工作区配色、语义图标与 CS-07 声线开场。

## 包含什么

| 模块 | 内容 |
| --- | --- |
| 主题 | 工作区配色（commander-v1 预设）、约 56 组明暗语义图标、入口徽记、主题角色 |
| 开场 | 12.5 秒有声开场，「单元-07 已就位」「CS-07 · 工作区已就绪。」，随后交接进入工作区 |
| 回复风格 | 随皮肤启用，统一称呼与语气 |

不含桌宠动作，桌宠由插件自带能力负责。

## 适配

- DSH：0.2.1-rc.5、0.2.2-rc.1
- 平台：macOS ARM64、Windows x64
- 插件：主题盒子 1.0.0 及以上

## 安装

1. 主题盒子 → 皮肤库 → 导入，选择 `commander-workspace-private-1.0.0.zip`。
2. 点「应用皮肤」。
3. 在「本套设置」里按需调整主题明暗、开场声音与时长。

## 说明

- 开场片为作者原创合成，含 CS-07 语音；不建议单独抽取音轨使用。
- 首次播放前确认桌面组件版本已更新，旧组件会提示 `STARTUP_NATIVE_UPDATE_REQUIRED`。
- 想要开机自动播放，勾选「启动时自动播放」。
