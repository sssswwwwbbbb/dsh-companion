## 已实现并修复

| 项 | 结果 |
| --- | --- |
| 插件与正式皮肤分离 | 安装包不再包含 skins/；旧版选中且已校验的缓存会迁入已安装库，保留选择和设置 |
| 在线皮肤库 | 激活后通过现有服务取得签名目录，按官方网络传输下载并核对 ZIP SHA/大小、manifest 和资源，然后安装；下载不自动应用 |
| 皮肤更新 | 同 id 的新版本显示下载更新；旧选择保持，用户自行应用；服务器拒绝同 id/版本不同摘要 |
| 卸载 | 当前皮肤先退出并确认清理，恢复后删除快照/运行资源；失败保留文件；默认保留设置，可显式清除 |
| 可下载皮肤数量 | 发码/管理接口与页面接受数字，0 不限量，旧码缺字段也不限量；按服务器累计 skin id，卸载不返还，版本更新与重装不重复计数，同码多设备共享 |
| 无皮肤旧入口 | 去掉桌宠控制和旧配置包导航；用户 start/replay 无选中被拒绝，内部 ZIP 文件选择器仍可启动无桌宠的 standby |
| 跨版本清除设置 | 保存内容摘要→皮肤 id 归属，清除同 id 的历史角色/回复风格会话选择，保留其他皮肤 |
| 兼容判定 | 在线按钮复用 Host 的 supportsSkinHost 结果，避免仅用版本数组造成误禁用 |
| 无桌宠界面动效 | 从 petEcho 条件解耦；已有会话工作反馈可作完成轻动效目标，关闭会停止执行提示点动效；未发送的输入、切换、停止、减少动态仍可取消 |
| 工作区角色合同 | commander-v1 静态角色只要求 avatar，可选名称/型号，不再强制制作不会在此版式播放的 WebM；旧动画版式合同保留、旧包摘要保持兼容 |
| Windows 打包依赖 | 托盘图标改用引擎自身图标，解除对被拆出的冷启动皮肤头像文件的构建依赖 |
| 独立皮肤工具包 | 包含同版真实校验器、依赖、样例、素材/开发说明和自交付说明，不需要本项目源码或 npm install |

- 独立审查发现的三项代码问题已修复，再审未发现该范围的新明确问题。动效与跨版本清除均有复现回归。

## 上线前仍需完成

1. 制作者按反馈修正正式分发说明、名称/描述和交付版本，出新 ZIP 与摘要。没有获准分发的包不作为可分发正式包上架；维护方不替作者猜测授权。
2. 将已本地验证的授权/皮肤库服务及管理页面部署到现有服务，使用新 `/v1/skins/*` 路由；保留授权数据库和签名身份并备份。当前线上还没有这些新路由。
3. 用最终通过的皮肤 ZIP 正式上架，再验证公网激活后的目录、下载、重复下载、名额与更新。当前发布工具已提供，后台自助上传界面尚未实现。
4. Windows 真机集中验证：覆盖安装保留授权/选择/设置；本地导入三包、明暗/125%缩放、原图标冷启动、预览/完整播放/跳过/静音、停用恢复、当前皮肤卸载与重新安装。在线服务切换后同一轮再测库下载和配额，不拆成频繁小版本验收。
5. 最终候选的用户视觉/声音验收。已有自动检查不替代此项。

## 不把后续能力当成本版完成

commander-v1 目前是小头像与状态反馈，不是完整半身循环视频演出。模型/工作区场景需绑定真实目标；三类提示默认开关来自各套皮肤。当前三个正式包没有 pet 模块，不应承诺系统桌宠。

图标替换依赖已支持的真实宿主位置。冷启动中5个预备键没有当前宿主目标，companion另走入口注入；不能把56份图标资源宣称为56个实际已命中的控件，也不为没有的宿主按钮造新界面。
