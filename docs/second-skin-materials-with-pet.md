# DSH 第二套皮肤素材清单 带桌宠版

> 2026-11-08 最新版开发说明与素材清单见 [主题盒子 1.0 交接包](skin-kit-v1/README.md)。下文保留旧制作记录，版本与能力以最新版为准。


本版覆盖工作区视觉、同窗开场、声音、文案和独立桌面角色。工作区、开场和桌宠统一使用本套视觉设定。

主题名、题材、主视觉和色板由提案确定。先交源稿和一组可预览的成品，确定方向后再展开可选素材。

## 一 基础素材

| 素材 | 数量 规格与交付 |
| --- | --- |
| 角色立绘与设定 | 1 份全身正面分层母版，附发色、瞳色、服装、标识、表情和动作参考。人物完整入画，源稿建议长边至少 2048 px。 |
| 工作区明暗关键稿 | 浅色、深色各 1 张。同一构图含侧栏、目录、会话正文、代码或表格、输入和选中状态。用接近实际 DSH 的窗口比例。 |
| 颜色与排版说明 | 1 份明暗色值表。标出底色、表面、正文、弱文字、边框、强调、成功、警告和错误的 HEX 值。附字号、字重与间距示意。 |
| 开场分镜与静帧 | 1 套简短分镜，含起始、主视觉和结束。交 opening-still.png 1 张，建议 1280×720，16:9。静帧可单独用于减少动态。 |
| 开场正片 | opening-film.mp4 或同名 WebM 1 段，建议 1280×720，5–12 秒。片尾留能自然接回工作区的画面，标注实测时长。 |
| 基础文案 | 1 份主题名、简介、开场标题和副标题。采用角色时附角色名、用户称呼与语气。采用声音时附台词和时间点。 |
| 桌宠待机 | role-idle.webm 1 段，透明，建议 2–4 秒。首尾可循环，首帧能停住。另交代表静帧、画布尺寸和脚点。 |
| 桌宠回应 | role-react.webm 1 段，透明，建议 1–2 秒。选择符合角色的一个清楚动作，片尾衔接待机。与待机使用同一人物比例、画布和脚点。 |

统一的视觉检查。把明暗界面、开场关键帧与主视觉放在同一张对照板。带桌宠版再并排放待机和回应关键帧。

## 二 可选界面素材与小演出

按本套主题选用下列增强。各项需明确使用位置，开发确认接入后再导出最终运行文件。

| 素材 | 要做的内容 |
| --- | --- |
| 聊天背景 | 1 张低对比无字背景，建议 1440×900，PNG、JPEG 或 WebP。另交一张实际叠到聊天区后的效果图。 |
| 成套功能图标 | 全套 56 枚，逐枚清单见后文。每枚交 1 份矢量源稿和 2 张浅深透明 PNG。 |
| 皮肤管理入口标识 | 1 枚主题标识，浅色与深色各导出 1 张透明 PNG，建议 96×96。可沿用陪伴图标的轮廓，按实际小尺寸检查。 |
| 工作区角色或场景元素 | 按实际布局交头像、半身图、全身静帧或场景徽记。头像建议 256×256 PNG。完整角色组件另备待机与回应短片。 |
| 封面及文字规范 | 1 张展示封面，建议 960×600 PNG，可另交无字底图。配字体名称、字号、字重和可用许可，方便开发复现。 |

### 小操作 执行状态 待机和小演出

| 选做场景 | 工作区要交的素材 | 桌宠可联动的素材 |
| --- | --- | --- |
| 小操作 | 从新会话、发送、复制成功、切换模型或打开文件中选场景。交初态、短反馈、终态和可选音效。 | 可加看向内容、点头或短句，以及回待机的衔接。 |
| 任务执行 | 开始、执行中、需处理、完成、停止或失败。交状态图标、短文案及选中的动效。执行中可有低亮度短循环。 | 可加专注姿态、提醒或完成动作，附静态替代。 |
| 工作区待机 | 在背景一角或徽记附近做低频短循环。交静帧、动效、循环点和恢复到稳定画面的终态。 | 可加本套角色的待机变化、视线或小动作。 |
| 主题小演出 | 按已选触发交分镜、关键帧、前后场景、短片或透明叠层、混音和跳过后的落点。 | 可加角色参与、道具出入、台词和表演后待机姿态。 |

每个入选动效附触发点、起止帧、静态替代和静音表现。保留 Figma 原型、AE 工程或等价动效源。独立声音交 WAV 和时间点。

## 三 声音与文案

开场可以有配音、音乐、环境声和音效。按实际入选轨道逐件交付。常驻工作区和桌宠按事件播放独立音效的增强项，由开发确认接入。

| 声音 | 文件及说明 |
| --- | --- |
| 开场配音 | 选用时交角色试音、逐句台词、无处理干声 WAV、字幕文本与时间码。每条干声以台词 ID 命名。 |
| 环境声及音乐 | 按入选场景交独立 WAV 或可编辑音轨，说明使用位置、起止点及需要时的循环点。 |
| 动作和转场音效 | 逐条交独立 WAV，例如上电、扫描、转场、动作和片尾落点。附对应画面及时间码。 |
| 最终开场混音 | 交带声音的成片、无声审看版、最终混音 WAV 及各分轨。建议源轨为 48 kHz / 24-bit WAV。 |
| 界面提示音 | 选做成功、需处理、操作彩蛋或专注计时提醒。每个入选事件交一条短音及静音时对应画面。 |
| 桌宠交互声与短句 | 按入选动作交点击、落地、回应或问候的独立声音。录音附原台词和触发点。桌宠文字回应可独立提交短句表。 |

### 主题人设与工作区回复风格

交一份文本。写角色身份、世界观、用户称呼、默认语气、回答详略及组织方式。附正常工作问答、解释错误和用户要求展开三组示例。该风格属于后续引擎功能，文案可单独交付。

另交桌宠的说话与行为文案。按实际入选的待机、执行、待处理、完成、主动互动等状态各写短句，标出什么时候安静。两端可以共用角色设定。

开场标题、副标题和台词请以可复制文本交付。带声音的素材记录作者、来源、授权、署名、可剪辑及可分发范围。

## 四 桌宠进阶动作与道具

按本套角色选择适合的动作和道具。走跑、坐躺、攀爬、读书喝茶可用来理解交付结构。每套皮肤可以设计自己的动作目录，后续由模型结合场景和可用素材选择行为。

| 可选动作 | 要交的素材 |
| --- | --- |
| 移动或变速 | 各选定方向交起步、稳定循环、减速、停步或转正。附脚点、步幅、朝向。需要脚步声时附落脚时间点。 |
| 改变姿态 | 为坐下、躺下、攀爬或本套专属姿态交进入、保持和退出。涉及窗口或道具时标手脚接触点和遮挡关系。 |
| 使用道具 | 透明道具分层、持握位置、人物取出、使用和收回的动作。附前后遮挡、出现和收起帧，可选短音效。 |
| 工作状态回应 | 按选中的专注、待处理和完成状态交代表静帧、短动作、短句及静音表现。明确打断后的结束方式。 |
| 角色形象变体 | 选做角色配色、徽标或装束变化。交默认形象、变体、过渡、头像及适用场景。完整换角色时另配待机与回应。 |
| 自主活动与中断 | 可复用待机、回正、结束和最短恢复片段。按角色选一组空闲行为，并写清适合什么场景、从哪个姿态开始及何时结束。 |

### 动作目录与透明文件

每个动作记录动作 ID、行为含义、适合场景、起止姿态、素材 ID、循环、道具、音轨和打断后的衔接。请为第一段动作交可编辑源和两种底色的边缘检查预览。

透明动作交真实 Alpha 的 WebM，并保留高分辨率源。可用 1920×1080、24 或 30 fps 作为源稿起点。统一画布、人物有效像素和脚点。成品按目标窗口实看控制边缘、抖动和大小。

## 功能图标清单 导航与对话

成套规格为 56 枚矢量源稿和 112 张浅深 PNG。矢量用 24×24 画板，PNG 为 96×96 px、sRGB、RGBA。按 16、20、24 px 实际显示尺寸检查识别度，保持同组的线宽、光学居中和留白。

以 send 为例，交 `source/icons/send.svg`、`exports/icons/light/send.png` 和 `exports/icons/dark/send.png`。浅深两版共用轮廓，并在各自背景上调整颜色。

## 素材包交付明细

| 目录 | 放入内容 |
| --- | --- |
| source/ | 可编辑角色、界面、图标、动效、开场和音频工程。注明软件及版本，包含链接依赖。 |
| exports/ | 实际使用的 PNG、WebM、MP4、浅深图标和成片。音频分轨放 exports/audio/。 |
| copy/ | 开场文案、字幕、主题回复风格稿、桌宠说话与行为文案。 |
| review/ | 明暗关键稿、角色或场景对照、开场分镜及素材台账。采用增强项时附触发、结束和静态替代。 |
| licenses/ | 逐件记录作者、来源、许可、署名和可分发范围，包含字体及声音等第三方素材。 |

台账每件一行。写明文件名、用途、资源 ID、宽高、格式、Alpha、时长、帧率、循环、作者、来源与授权。桌宠素材另记脚点、道具锚点与起止姿态。

运行素材限制为单图 8 MiB、单视频 16 MiB、声明资源合计 128 MiB 且最多 128 项。源文件单独留在素材包，开发者负责选用及打包。
