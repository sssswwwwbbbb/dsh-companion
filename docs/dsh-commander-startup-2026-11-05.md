# 机械姬 × 指挥官 · 原生开场桌面验收

Mac arm64 私有桌面实测通过，提交主控复核。候选皮肤 **commander-workspace-private 0.2.0**，DSH **0.2.1-rc.5**，私有插件与原生执行器 **0.1.0-dev.11**。工作区主题、原生桌宠和既有媒体沿用主控已通过的版本，仅加入新的静音开场与真实工作区交接。日用安装、旧 0.7.1、R2、有限左走与 H4 的冻结和旧证据继续保留。

实际私有桌面窗口为「DSH 机械姬 · 原生开场验收」。从 **陪伴 → 本套设置 → 预览开场** 可复核：走廊过场、开舱与机械姬登场，随后两侧遮板收起并回到原会话。按 **Esc** 可提前返回。再次打开该入口也可开启「减少开场动态」查看同角色静态画面。交审时三个模块均就绪，自动启动、自动开场、启动入口和减少动态开关均为关闭；影片无音轨。
