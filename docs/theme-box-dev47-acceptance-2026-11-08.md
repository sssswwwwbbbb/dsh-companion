# 主题盒子 dev.47 集中验收

本节点基于用户已验收的 dev.46，交付 Mac ARM64 与 Windows x64 候选。兼容范围仍为官方 DSH 0.2.1-rc.5、0.2.2-rc.1。Windows 实机与用户实际模型体验等待本轮集中验收；本次未覆盖安装日常 Mac 客户端，未发布远端版本。

## 本轮变化

- 工作区与桌宠可选共用主题角色，分别配置场景补充；角色名、身份、场景补充按皮肤保存。工作区仍需在各会话开启「主题角色」，桌宠独立开启「桌宠使用主题角色」。
- 回复风格默认开启，按皮肤记住最近开关作为新会话默认。明确选择过的会话保留自己的开关。回复风格与角色身份独立。
- 冷启动桌宠接入现有 dsh-pet 文字气泡。开启智能互动和允许说话后能展示模型文字回复。本节点没有新增 TTS。
- 回前台时先续约再处理皮肤状态，避免后台计时器暂停后先清除配色。插件停用和真实通信失败仍清理效果。
- 内置冷启动升级为 0.7.1，发送与停止图标改为实心琥珀。旧快照与导入版继续识别，原选择不会被自动替换。
- 移除内置 MVP 档案暖白、构建输入和旧内容目录。当前冷启动、第三方导入、授权与其余设置保留。若旧 profile 还选中已移除的内置 MVP，会停止该效果并回到未选择状态，可从皮肤库选择冷启动。主动导入的用户皮肤继续保留。

## 一次集中验证

1. **覆盖升级与图标**：在 DSH 添加插件处覆盖安装对应平台 dev.47。确认授权、当前皮肤、桌宠大小、开场和场景偏好保留，内置库不再显示档案暖白。若当前选的是旧版冷启动，在库中应用 0.7.1 后检查输入框发送与停止图标。
2. **回前台配色**：打开一个会话，切到其他应用或最小化 DSH，等 10 秒后切回。重复一次，确认配色没有短暂变回原生。检查停止本套效果后仍正常清理。
3. **回复风格**：在会话标题确认回复风格已开，修改称呼和语气，创建新会话发送一句话。新会话应默认已开并使用当前设置。单独关闭一个会话，再在另一个会话开启，前者应保持关闭，之后新建会话应沿用最新的已开默认。
4. **共用角色与桌宠**：在「本套设置 → 角色」修改角色名、身份和两个场景补充，保存。当前工作区会话打开「主题角色」，问角色身份。选择可用的桌宠互动模型，开启智能互动、允许说话与「桌宠使用主题角色」，从专属互动输入询问身份，观察桌宠气泡。两端使用同一身份，各自场景补充不串用。关闭桌宠共用后恢复原有独立人设；关闭工作区角色后下一轮不再加入该人设。
5. **恢复与冷启动**：完全退出，再从原 DSH 图标打开。检查自动开场、桌宠、角色文本、回复风格默认、场景和活动偏好保留。停止与恢复本套后确认开关和参数仍在。

## 已完成证据

140 项自动测试通过。两版官方 DSH 的隔离界面通过配置、会话开关、模型调用输入、回复风格记忆及暂停 5.2 秒后的逐帧配色采样。官方系统提示词装配通过作用范围、修改生效、停止和停用清理检查，保留宿主其余指令和工具。真实 Mac dsh-pet 独立进程通过文字气泡、文本独立更新、动作取消和自然恢复等 7 项检查。

隔离界面使用官方模型服务与本地确定性模型，桌面桥接在该界面中模拟；真实桌宠播放另在独立进程验证。两平台安装包的同源代码、运行时摘要和仅内置冷启动均已核对。Windows 实机表现、实际外部模型的角色表达质量仍由本次用户集中验收确认。
