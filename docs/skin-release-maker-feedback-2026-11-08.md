## 一、上线前请处理

### 冷启动

1. 当前 `skin.json.description` 写“工作区、桌宠及 CS-07 声线开场”，但 modules 只有 theme/startup。请改成“工作区主题/角色位与开场”，明确本包没有系统桌宠。
2. 当前资源许可仍有“private isolated candidate, no distribution license assigned”等试作说明，包内没有正式分发许可附件。请按实际已经取得的授权补齐 LICENSE.md / 署名，并同步 description 与 assets.*.license。这里是交付声明一致性问题，维护方不替作者编造授权。
3. 请出新版本并附 SHA-256，建议 0.9.5；不要覆盖已交付 0.9.4 的内容后沿用旧摘要。

### 烬角黑焰

1. 当前包内 109 项资产标注“非商业二创，不可分发”，description 为“仅限本地自用”，没有 LICENSE.md；源 README 也有“不公开分发、不上架、不做公开演示”。这与本次正式在线分发的目标直接冲突。
2. 请按真实授权明确哪些范围可以分发、是否需署名，并统一 LICENSE.md、description、assets.*.license 与交付 README。若某项仍只允许本地自用，请明确保留限制并标出，不能混成可分发包。
3. 正式名称请在交付说明里统一为“烬角黑焰”；目前 manifest.name 为“黑焰”，皮肤库可用“烬角黑焰”展示，但本地导入会显示 manifest.name。
4. 请出新版本并附 SHA-256，建议 0.2.1。另有 `-dev35.zip` 是旧目标候选，本轮正式交付不要拿它替代当前包。

### 天空龙

1. 1.0.4 的 LICENSE.md 已写 Dr.S 授权公开分发，107 项资产说明也一致，但 description 仍是“私有二创，仅限个人本地使用”。请按现有真实授权统一 description，避免包本身自相矛盾。

3. 请出新版本并附 SHA-256，建议 1.0.5。

## 二、无需制作者追加素材或修改插件的事项

- “界面动效”在无桌宠包中原先被 petEcho 条件挡住：由引擎修复，不要求加桌宠。
- 旧桌宠入口、下载名额累计、卸载、历史设置清除、兼容判定：由引擎处理。
- 当前 commander-v1 的侧栏角色位显示小头像与工作状态，不表示已经实现完整半身循环或角色视频演出。冷启动已有 idle/react 不等于在该版式中自动播放，1.1.0-dev.3 已将当前静态角色位合同收敛为只需头像，旧包兼容；完整角色视频演出仍属于后续能力，不在本版宣传范围。
- 冷启动多出的 bookmark/history/mute/quote/volume 在当前宿主没有对应已支持的替换位；companion 使用插件入口注入。无需为它们重复画素材，也不应宣传为 56 个真实控件都已替换。其余实际命中仍以宿主实机为准。

## 三、技术检查已通过的部分

三包全部资源引用、哈希及基础文件头通过；图片声明尺寸未发现不一致。三开场都是 1280×720、约 24 fps、H.264/AAC 双声道 MP4。实际时长与声明差异均在现有播放器可处理范围，不需要为此重做视频或交静音版。声音关闭由播放器静音控制。
