# 主题盒子皮肤升级与永久授权优化交接

日期：2026-11-08。用途：安排产品规则调整、开发与验收。本文记录现状与建议方案；尚未实施代码修改或部署。

本次优化涉及两处体验：同一皮肤下载新版后，应有清晰的升级行为；永久授权应明确已安装内容的离线使用权。两项均需保留已有授权、皮肤设置和用户数据。

## 一 同一皮肤的版本升级

### 当前行为与问题

安装按包内容标识 `contentKey` 保存快照。相同内容重复安装会去重，同一皮肤 ID 的不同版本则分别保留，显示为多条已安装记录。下载完成只安装，不自动切换；当前使用旧版时，仍需手动应用新版。

因此，用户点击下载新版后可能误以为已升级，实际仍在运行旧版；长期更新还会积累旧包，使列表和磁盘占用增加。

额度按激活码下已领取的不同皮肤 ID 计算。同 ID 更新、重装及本地保留多个版本均只占一个名额；不同 ID 会另占名额。卸载不返还领取名额，`skinLimit=0` 表示不限量。这部分无需因版本升级而改变，界面应称为“可领取皮肤数”，避免被理解为可同时安装数量。

### 建议规则

1. 以皮肤 ID 识别同一套皮肤，以内容标识区分具体安装包。市场显示“有更新／更新皮肤／已是当前版本”，同时明确本地和市场版本。
2. 首次下载继续只安装，由用户决定是否应用。同 ID 的新版下载按升级处理；若旧版正在使用，升级成功后切换到新版；未使用的皮肤更新后保持当前其他皮肤不变。更新操作旁说明“正在使用时，更新成功后自动应用”。
3. 保留用户已有设置，按现有配置兼容规则迁移；新版新增项使用默认值。不重置授权、智能配置或对话记忆。
4. 新包校验和安装成功后再切换。应用失败时恢复旧版及其设置，显示失败原因；取消下载、下载失败均不影响当前皮肤。
5. 普通列表按皮肤 ID 展示一条记录。保留最近一个可回退版本，并提供简单的回退入口；成功升级后清理更早的包时，只清理引擎管理的缓存，不删除原始 ZIP、素材或用户数据。设置迁移应保留回退所需的旧状态。
6. 同版本重复下载保持幂等。市场版本低于本地时不自动降级；主动回退与正常更新分开处理。作者必须保持同套皮肤 ID 稳定，并在内容变更时递增版本。

### 验收要点

- 正在使用 A 旧版时更新 A：成功后运行新版，原设置保留，领取数量不变。
- 正在使用 B 时更新 A：B 继续运行，A 的已安装记录更新且不重复堆叠。
- 下载失败、取消、包校验失败或新版应用失败：旧版仍可使用，失败不会丢失设置；回退后配置可恢复。
- 重装、重复点击、额度已满时更新已领取的同 ID 皮肤：不重复计数，不因满额拒绝该更新。满额领取新 ID 仍被拦截。
- 客户端升级时，已有多版本安装记录可收拢展示，并保留当前选择和必要回退包。

## 二 永久授权与离线使用

### 当前行为与问题

截图显示“授权到期 永久 · 离线可用至 2026/11/15 21:00:08”。这两个字段分别表示授权本身无到期日，以及本地授权凭证有离线期限。

当前服务端默认签发约 7 天离线凭证，联网刷新成功后延长。客户端即使识别为永久授权，也会检查 `offlineUntil`。持续断网或授权服务不可达，超过该时间后会进入需刷新授权状态，并影响本地功能；这不是单纯的文案问题。

“永久激活”容易让用户理解为激活后可长期使用，而当前规则要求定期连接授权服务。服务故障也可能使有效永久用户无法继续使用已安装内容。

### 建议规则

1. 永久授权首次激活并完成设备绑定后，已安装内容可长期离线使用。网络异常或在线凭证过期，不应单独成为停用本地皮肤、开场和桌宠基础功能的原因。
2. 云市场领取、下载和在线更新继续服务端校验授权、设备绑定和额度。在线凭证可以有期限，过期后自动刷新；网络失败时仅提示相关在线操作暂不可用。
3. 保留签名校验、设备绑定和明确的撤销处理。收到有效的吊销或设备解绑结果后按既定策略限制使用；普通超时、断网不能被当成吊销。长期离线无法实时获知撤销，这是长期离线使用策略需要接受的边界。
4. 永久授权与限时授权分别处理。限时授权仍按真实到期时间限制使用；不得通过此次修改把所有授权统一改为永不过期。
5. 兼容现有永久激活码和已绑定设备，不要求重新购买或清空本地状态。凭证格式如需调整，应提供自动迁移，并覆盖旧凭证已超过离线期限时的恢复路径。
6. 页面主文案调整为“永久授权 · 本机已激活”，补充“已安装内容可离线使用；云市场和更新需要联网”。上次联网校验时间可作为辅助信息，避免继续把在线凭证期限呈现成永久使用权的截止时间。文案须与实际策略同步发布。

### 验收要点

- 永久激活后断网超过原 7 天期限，再次启动及持续运行均可使用已安装内容，设置和数据保留。
- 授权服务超时、不可达或临时错误：本地使用继续，在线功能显示可理解的提示；联网恢复后可正常刷新、下载和更新。
- 服务端明确吊销、释放设备及签名伪造、设备不匹配仍被正确处理。离线无法实时撤销的限制在产品规则中明确。
- 限时授权到期行为保持正确，永久与限时授权切换不串用权限或额度。
- 现有永久用户覆盖升级后保留激活状态，旧离线凭证过期场景有明确且可验证的迁移结果。

## 三 实施范围与代码入口

优先落实永久授权的本地使用策略，再补齐同 ID 皮肤升级、失败恢复和列表展示。仅隐藏日期或删除旧版列表项，都不能完成对应优化。无需引入复杂版本管理中心或扩大市场功能范围。

| 范围 | 代码入口 |
| --- | --- |
| 本地包安装与快照索引 | `packages/dsh-companion/src/skin-library.mjs` |
| 皮肤注册与选择 | `packages/dsh-companion/src/skins.mjs` |
| 下载完成处理 | `packages/dsh-companion/src/skin-downloads.mjs` |
| 皮肤库及授权界面 | `packages/dsh-companion/src/skin-settings-ui.mjs` |
| 领取额度 | `licensing/skin-quota.mjs` |
| 服务端凭证签发 | `licensing/server.mjs` |
| 本地凭证验证与刷新 | `packages/dsh-companion/src/license-core.mjs`、`packages/dsh-companion/src/entitlement.mjs` |
| 授权失效后的运行处理 | `packages/dsh-companion/src/controller.mjs` |
