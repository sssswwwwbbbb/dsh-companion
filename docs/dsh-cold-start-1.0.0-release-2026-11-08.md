## 三、安装与使用

**云端（推荐）**：已激活的主题盒子 → 皮肤库 → 刷新 → 选「冷启动 1.0.0」→ 下载 → 安装 → 应用。同 id 新版对已安装用户免费重下。

**本地**：皮肤库 → 导入 ZIP → 选 `commander-workspace-private-1.0.0.zip` → 应用。

常用设置（均随皮肤保存、可覆写）：

- **开场声音**：默认开启；想静音可在「本套设置」关闭
- **减少开场动态**：系统减少动态时回落到静帧
- **工作区细节 / 界面动效 / 入口徽记**：分别控制语义图标、动效与侧栏入口徽记
- **场景提示**：三条各自有开关、时长、位置、效果，可预览
- **场景**：把工作区配色或模型徽记绑定到实际工作区 ID / provider-model
- **角色与回复风格**：可逐会话开启角色；回复风格可改称呼与语气

## 六、已知限制

1. **不含桌面宠物**：0.9.0 起移除 `pet` 模块，设置页不显示桌宠与角色桌宠侧；恢复需重新提供动作素材。
2. **图标覆盖 46/50 位**：`bookmark` / `history` / `mute` / `quote` / `volume` 引擎侧仍无替换位；`companion` 走插件入口注入，不受替换表控制。
3. **模型场景需手动绑定**：三组徽记只是预设，实际模型由用户在设置里绑定 provider/model；工作区配色同理。
4. **场景提示是文本容器**：不支持角色视频演出、新会话空白页开场或整屏转场（1.0 接口限制）。
5. **开场音频**：CS-07 为本地合成声线，非真人声优；不得单独传播该音频。

## 七、更新与回滚

- **发新版**：保持 id 不变、提升 version，重复「校验 → 本地验收 → 发布 → 下载回归」。服务端对同版本同摘要幂等，不会重复登记。
- **同版本内容冲突**：避免；如改内容必须升版本。
- **回滚**：保留上一版冻结 ZIP；已安装用户可暂时选回本机保留的旧版本，或等更高版本修正。服务端不提供自助撤回。
- **不要换 id 发更新**：会被视为另一套皮肤，占用用户下载名额。
