# DSH 第二套皮肤素材清单 无桌宠版

> 2026-11-08 最新版开发说明与素材清单见 [主题盒子 1.0 交接包](skin-kit-v1/README.md)。下文保留旧制作记录，版本与能力以最新版为准。


本版覆盖工作区视觉、同窗开场、声音和文案。工作区与开场可以采用角色主视觉，也可以围绕场景或主题标识设计。

主题名、题材、主视觉和色板由提案确定。先交源稿和一组可预览的成品，确定方向后再展开可选素材。

## 一 基础素材

| 素材 | 数量 规格与交付 |
| --- | --- |
| 主视觉与风格设定 | 1 份可编辑的场景或角色主视觉，附题材元素、配色和图形语言。选角色时保留分层立绘和表情参考。 |
| 工作区明暗关键稿 | 浅色、深色各 1 张。同一构图含侧栏、目录、会话正文、代码或表格、输入和选中状态。用接近实际 DSH 的窗口比例。 |
| 颜色与排版说明 | 1 份明暗色值表。标出底色、表面、正文、弱文字、边框、强调、成功、警告和错误的 HEX 值。附字号、字重与间距示意。 |
| 开场分镜与静帧 | 1 套简短分镜，含起始、主视觉和结束。交 opening-still.png 1 张，建议 1280×720，16:9。静帧可单独用于减少动态。 |
| 开场正片 | opening-film.mp4 1 段，H.264/AAC，建议 1280×720，5–12 秒。片尾留出回到工作区的画面，标注实测容器时长。由播放器静音。 |
| 基础文案 | 1 份主题名、简介、开场标题和副标题。采用角色时附角色名、用户称呼与语气。采用声音时附台词和时间点。 |

统一的视觉检查。把明暗界面、开场关键帧与主视觉放在同一张对照板。带桌宠版再并排放待机和回应关键帧。

## 二 可选界面素材与小演出

按本套主题选用下列增强。各项需明确使用位置，开发确认接入后再导出最终运行文件。

| 素材 | 要做的内容 |
| --- | --- |
| 聊天背景 | 1 张低对比无字背景，建议 1440×900，PNG、JPEG 或 WebP。另交一张实际叠到聊天区后的效果图。 |
| 成套功能图标 | 全套 56 枚，逐枚清单见后文。每枚交 1 份矢量源稿和 2 张浅深透明 PNG。 |
| 皮肤管理入口标识 | 1 枚主题标识，浅色与深色各导出 1 张透明 PNG，建议 96×96。可沿用陪伴图标的轮廓，按实际小尺寸检查。 |
| 工作区角色或场景元素 | 按实际布局交头像、半身图、全身静帧或场景徽记。头像建议 256×256 PNG。完整角色组件另备待机与回应短片。 |
| 封面及文字规范 | 1 张展示封面，建议 960×600 PNG，可另交无字底图。配字体名称、字号、字重和可用许可，方便开发复现。 |

### 小操作 执行状态 待机和小演出

| 选做场景 | 工作区要交的素材 |
| --- | --- |
| 小操作 | 从新会话、发送、复制成功、切换模型或打开文件中选场景。交初态、短反馈、终态和可选音效。 |
| 任务执行 | 开始、执行中、需处理、完成、停止或失败。交状态图标、短文案及选中的动效。执行中可有低亮度短循环。 |
| 工作区待机 | 在背景一角或徽记附近做低频短循环。交静帧、动效、循环点和恢复到稳定画面的终态。 |
| 主题小演出 | 按已选触发交分镜、关键帧、前后场景、短片或透明叠层、混音和跳过后的落点。 |

每个入选动效附触发点、起止帧、静态替代和静音表现。按当前产能提交成品与参数表。开场交 H.264/AAC MP4，静态资源交 PNG/WebP。独立声音用 48 kHz／24 bit 立体声 WAV，事件音效等引擎接入后交付。

## 三 声音与文案

开场可以有配音、音乐、环境声和音效。按实际入选轨道逐件交付。工作区按事件播放独立音效的增强项，由开发确认接入。

| 声音 | 文件及说明 |
| --- | --- |
| 开场配音 | 选用时交角色试音、逐句台词、无处理干声 WAV、字幕文本与时间码。每条干声以台词 ID 命名。 |
| 环境声及音乐 | 按入选场景交独立 WAV 或可编辑音轨，说明使用位置、起止点及需要时的循环点。 |
| 动作和转场音效 | 逐条交独立 WAV，例如上电、扫描、转场、动作和片尾落点。附对应画面及时间码。 |
| 最终开场混音 | 交带声音的成片、无声审看版、最终混音 WAV 及各分轨。建议源轨为 48 kHz / 24-bit WAV。 |
| 界面提示音 | 选做成功、需处理、操作彩蛋或专注计时提醒。每个入选事件交一条短音及静音时对应画面。 |

### 主题人设与工作区回复风格

交一份文本。写角色身份、世界观、用户称呼、默认语气、回答详略及组织方式。附正常工作问答、解释错误和用户要求展开三组示例。该风格属于后续引擎功能，文案可单独交付。

开场标题、副标题和台词请以可复制文本交付。带声音的素材记录作者、来源、授权、署名、可剪辑及可分发范围。

## 功能图标清单 导航与对话

当前可接入 50 枚工作区图标和 1 枚独立主题盒子入口徽记。其余 5 枚归入待接入素材。矢量用 24×24 画板，PNG 为 96×96 px、sRGB、RGBA。按 16、20、24 px 实际显示尺寸检查识别度，保持同组的线宽、光学居中和留白。

以 send 为例，交 `source/icons/send.svg`、`exports/icons/light/send.png` 和 `exports/icons/dark/send.png`。浅深两版共用轮廓，并在各自背景上调整颜色。

## 素材包交付明细

| 目录 | 放入内容 |
| --- | --- |
| source/ | 可编辑角色、界面、图标、动效、开场和音频工程。注明软件及版本，包含链接依赖。 |
| exports/ | 实际使用的 PNG、WebM、MP4、浅深图标和成片。音频分轨放 exports/audio/。 |
| copy/ | 开场文案、字幕、主题回复风格稿。 |
| review/ | 明暗关键稿、角色或场景对照、开场分镜及素材台账。采用增强项时附触发、结束和静态替代。 |
| licenses/ | 记录来源、可分发范围，包含字体及声音等第三方素材。 |

台账每件一行。写明文件名、用途、资源 ID、宽高、格式、Alpha、时长、帧率、循环、作者、来源与授权。工作区增强另记触发点、结束状态与静态替代。

运行素材限制为单图 8 MiB、单视频 16 MiB、声明资源合计 128 MiB 且最多 128 项。源文件单独留在素材包，开发者负责选用及打包。
