# 主题盒子 1.0.0 封版记录

日期：2026-11-08。版本 `1.0.0`，构建号 `10000`，插件身份仍为 `dsh-plugin-companion`。本次按用户要求，在优化三个场景提示后冻结代码并做本地 Git 提交。对应内容由本地 `v1.0.0` 标签定位。

## 本版包含

三类提示分别提供位置、1–8 秒时长、直接显示/淡入/轻移入场，容器有底色、边框和内边距；支持皮肤明暗色、独立覆写和预览。回归默认居中，切会话默认在输入框右上方，切工作区默认在窗口右上角。输入框锚点使用官方 `conversation.input.overlay`；全局提示使用 `shell.overlay`。缺少活动输入框时回退右上角。

包含此前已验收的主题、开场、桌宠、共享人设、回复风格、计时与勿扰、场景映射、自主活动，以及本批连续陪伴/近期记忆。冷启动内置为 0.7.1，MVP 档案暖白已移除。

## 一次集中实机验收

1. 覆盖安装 1.0.0，确认授权、皮肤、大小、开场与其他设置保留；完全退出后仍从原 DSH 图标打开。
2. 在「本套设置 → 常用 → 工作区场景提示」为三条分别选不同位置、时长和效果。点预览确认返回会话、位置清晰且不挡输入。设置 6 秒时确认不会在约 3 秒消失。
3. 同工作区切换两个已有会话，跨工作区进入另一会话；离开应用 15 秒后返回。分别观察相应提示。仅展开目录不会触发，欢迎每分钟最多一次，两个切换提示各间隔至少 4 秒。陪伴勿扰、换肤和停止应清理提示。
4. 在「更多 → 连续陪伴」开启近期记录，设置偏好并发一句专属代号。完整重启后继续询问，查看记录。清空保留偏好；关闭清空记录；恢复默认恢复本套开关和偏好。
5. 复验开场预览/跳过、桌宠缩放与文字、主题角色、回复风格及停止/恢复。操作设置应复用原桌宠进程，不出现额外应用启动流程。
